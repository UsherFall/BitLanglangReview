>

---

## 一、判定口径（三句话）

判的是**结构饱满不饱满**，不是"安静了多久"。**时长是充分不必要条件**：久不久既不保证好、也不因为短就淘汰。

1. **是** —— 收敛之前**真有过一段像样的行情（前期波幅够大）**，而且**振幅是逐步缩小的**（越来越小，不只是"现在比前面小"）；上下沿大致水平、价格没有离开这个区间。
2. **不是** —— 前一段本来就没什么波幅（没有前戏的窄幅不是蓄力）；或振幅没有缩小、只是横着；或上沿明显向下斜；或价格已经离开区间。
3. **说不清** —— 介于两者之间时用。允许大量使用，不要硬凑成"是/不是"。

**注意**：不要用"持续天数不够"当理由。窄而久 ≠ 好，宽而短 ≠ 差，看的是上面两条。

## 三、理由标签表

标注页的理由下拉项与这里一一对应。**理由是给未来的你用的**：它让同一批标签既能重标定阈值、也能训练模型。

| 理由 | 什么情况用 |
| --- | --- |
| 前期波幅不够 | 收敛之前没有像样的行情，"前戏"太薄 —— 窄得没来由 |
| 振幅没缩小 | 看着窄，但不是"逐步变小"，只是一直横着 |
| 上沿斜 | 区间上沿或下沿明显倾斜，不是水平箱体 |
| 位置太高 | 结构本身可以，但已在区间上沿 / 涨幅已走完 |
| 就是好 | 无可挑剔，直接要 |
| 其他 | 用备注补充（请在 note 里写清） |

> **不要用"时间太短"**：时长是充分不必要条件，它既不是好结构的理由，也不是淘汰的理由。
> 如果实际标注中反复出现表里没有的理由，**先加到这里，再继续标**——不要用"其他"糊过去。

## 四、一致性自检（放量之前做一次）

1. 从已标过的里面挑 20 张（含"是""不是""说不清"各若干）。
2. 隔几天，不看你上次的答案，重新标一遍。
3. 数一致率：**≥ 17/20** 才算口径稳，可以继续放量；**低于 15/20** 说明口径太模糊，回第一节重写，然后重标。

对照 `out/labels-*.csv` 里的 `instrument` 找同名记录即可。

## 五、边界（不要越界）

- 只判**日线（1D）**。小级别、其它周期都不在这一轮。
- 不预测涨跌、不考虑成交量、不看基本面——只看图形结构本身。
- 允许"说不清"，且鼓励使用：一个诚实的"说不清"比一个勉强的"是"值钱。
