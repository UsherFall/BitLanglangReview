# 收敛判据改「以大行情为分界」：找震荡转大行情

> 依赖：`10-15-labeling-history-window`（往前翻页取长历史的能力 + 「只有最新一页刷新」的缓存策略）。
> 状态：planning。**判据的量与阈值需要一轮真实数据标定**，本 PRD 只定形态与约束，候选口径见 §待标定。

## Goal

把判据从「最近一段比**等长**的前一段安静」（今天的 `detectConvergence`）改成：

```
[ 大行情 ] → [ 震荡/收敛 ] → 机会就发生在这
     ↑ 分界
  带的起点 = 上一段大行情的结束
  带的长度 = 大行情结束到现在（不固定）
  "前期波幅够不够大" = 上一段大行情本身够不够像样
```

用户 2026-10-15 原话：「这个判定器长度要灵活，要**以前一段大行情为分界**，大行情后面往往都是震荡，我们找的是**震荡转大行情**的机会」。

**今天的做法正好是它的反面**：`detectConvergence` 让带永远结束在最新一根、起点从最近往前滑，再用**等长**的前一段当基准比中位波动 —— 长度是隐式写死的，且基准与"有没有过一段大行情"无关。

## 已知约束

| 项 | 约束 |
| --- | --- |
| 窗口长度 | **必须跟着「上一段大行情」走**，不得用固定长度或等长前段 |
| 时长 | **不是判据**（充分不必要条件）；不得以"成熟度/天数"形式混进来 |
| 量 | 只能用**客观量**（幅度、波幅、方向性）；**不得**回到 swing/几何形态命名（2026-08-13 已整体删除 swing/几何检测，`archive/2026-08/08-13-narrow-box-redesign`） |
| 历史 | 按大行情分段就必须看到 >90 天；Bitget `/candles` 只回溯 ≈3 年、`/history-candles` ≈7 年，单次 90 根需翻页 → **复用依赖任务的翻页能力** |
| 口径对齐 | 判定口径与理由集写在 `tools/labeling/label-rubric.md`：**前戏不足 / 收缩没到位 / 就是好** |

## Requirements

### R1 判据改为分段式

- **R1.1 分段**：在序列上定位**最近一段大行情**；其**结束点**即候选带的起点。
- **R1.2 带**：从该结束点到最新一根。长度**不固定**，由分段结果决定。
- **R1.3 第一轴「前戏」**：用**大行情本身的幅度**度量，且**相对本币自身**（用户 2026-10-15 选定：不看绝对百分比，免得把本来就不怎么波动的币系统性排除）。
- **R1.4 第二轴「收缩」**：带内振幅**逐步**缩小（不只是"现在比前面小"），且未离开带的区间。
- **R1.5 输出**：沿用现有 `StructureResult` 契约形状（`structure` / `position` / `score` / `qualified`）—— 但语义需重新定义并在 spec 里写清；`scanTimeframes` 五档照旧。

### R2 线上取数窗口跟着拉长

- 扫描改为请求足够覆盖「大行情 + 之后震荡」的历史（**先 1 年**，与依赖任务一致）。
- **R2.1 成本**：必须走依赖任务的缓存策略。冷启动一次约 +1.5 分钟；**稳态不得每轮重付**。
- **R2.2 限频**：不自作提高 20 req/s；429 走既有退避 + `warnings`。

### R3 标注与标定

- 标注工具与口径模板**不动**（依赖任务负责把图变长）。
- 判据改动必须**先在标注数据上验证**：能分开用户认可的正面样本（如「大饼突破历史新高前的那段收敛」）与「收缩干净但前戏太薄」的负例，再定阈值。
- 若一轮标定不成立，允许回退到"只加长窗口、不改判据"。

## 待标定（研究阶段回答，不在 PRD 里定死）

1. **「大行情」怎么算出来？** 候选口径：
   - 幅度：段内净位移 `/` 起始价（再除以本币自身的波幅尺度做归一）
   - 方向性：净位移 `/` 段内逐根位移之和（效率比 / Kaufman ER）—— 接近 1 = 单边推进，接近 0 = 震荡
   - 二者组合：一段"幅度够大 **且** 方向性够强"的推进才算大行情
2. **门槛值**：幅度与方向性的分位/倍数取多少？必须做敏感性分析（历史上 `T±1` 就掉样本的教训）。
3. **找不到大行情时怎么办**：一直在震荡的币（例如上市即横盘）应判"无前戏"还是"不参与"？
4. **进打分还是进门槛**：第一轴是折进 `score`，还是当 `qualified` 的硬门槛？
5. **是否破坏已验标定**：粗筛（`research/coarse-1d-percentile.md`）那一轮的结论要不要重跑。
