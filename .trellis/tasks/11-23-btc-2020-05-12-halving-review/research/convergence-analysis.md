# BTCUSDT 2020 回放：「收敛」判断专项审计

> 对象：11 个带「收敛」标签的 Paper Rounds，加上批注写「小级别收敛突破」的 `position-22`，以及「无逻辑」反例 `position-43`，共 13 个样本。  
> 核心原则：只拿入场前已经封闭的 K 线判断当时可见性；后续突破只能验证结果，不能倒推入场时结构已经完成。  
> 边界：量化只描述，不自动判定“是不是收敛”。历史上多种自动识别方案已经被真实标注证伪，本报告不走第 10 次老路。

## 一、结论先行

### 1. 这批「收敛」至少混合了四种东西

1. **波动收窄**：最近一段高低区间相对前一段缩小，如 `position-25` 的 4H、`position-46` 的 4H、`position-34` 的 1H。
2. **水平箱体横住**：价格在一个区间内反复，不一定比前一段安静，如 `position-7 / 10 / 19 / 22 / 28 / 31 / 34`。
3. **几何或趋势结构收敛**：低点抬高、高点下移、趋势线被靠近或突破，如 `position-1 / 13 / 37`；这种收敛可以仍然很有分歧、振幅很大。
4. **结构转换前的停顿**：真正做空依据是假突破、反弹失败或结构破坏，横住只是等待过程，如 `position-28 / 31`。

所以，「收敛好了」不是完整策略语言。必须补出：**哪段行情之后、在哪里、以什么方式收敛、由什么触发入场。**

### 2. 你的实际判断顺序更接近「方向与位置在前，收敛在后」

这与此前人工标注任务中形成的框架一致：

- 结构是否饱满：前面有没有一段值得参考的上涨、下跌、假突破或承接；
- 位置是否有偏向：高位保持、箱体上沿/下沿、压力位附近，还是区间中部；
- 收敛是否成形：箱体、低波动、至少一条收敛边，或趋势线附近的停顿；
- 触发是否出现：突破、回踩、假突破收回、反弹结构破坏，还是仅仅提前猜方向。

**只有第三条叫“收敛”也不足以开仓。** `position-43` 就是最好的对照：图上确实能找出横盘和低波动，但没有形成有优势的方向计划。

### 3. 本批最完整的样本不是同一种形态

- `position-25`：上涨后高位箱体收敛，保留大部分涨幅，多头延续链条最完整。
- `position-46`：长期低波动筑底后，1H 开始转强，是“底部收敛 + 小级别启动”；不能在入场时就说“主升已确定”。
- `position-1`：宽幅分歧中的多次承接和边界收敛，不是低波动收敛。
- `position-28 / 31`：假突破后的反弹停顿与转弱，做空核心不是箱体本身，而是上方失败和下方结构。

### 4. 需要修正的两种事后表达

- `position-46` 的“主升开启”是结果描述，不是入场时可确认的事实。
- `position-43` 的“无逻辑”不应理解成“没有形态”，而应理解成“没有形成位置、方向、触发和失效位完整的交易逻辑”。

## 二、研究方法与辅助量

### 2.1 图和证据分层

`research/out/convergence-position-*.png` 为每个样本生成 4H/1H 对照图：

- 红绿 K 线：入场前已封闭；
- 黄色 K 线：入场所在 K 线，完整 OHLC 不能全部当作盘前信息；
- 灰色 K 线：入场后走势，只用于验证结果。

由于回合没有保存当时实际使用周期，本报告把 4H/1H 作为结构核对窗口，不宣称它们就是当时屏幕上的唯一周期。

### 2.2 `s20` 只表示波动收窄，不代表结构好坏

```text
range(N) = 最近 N 根最高价与最低价跨度 / 区间平均收盘价
s20      = 入场前最近 20 根的 range ÷ 紧邻前 20 根的 range
```

- `s20 < 1`：最近 20 根比前 20 根窄，仅表示波动收缩；
- `s20 > 1`：最近 20 根反而更宽，不代表没有箱体或趋势线收敛；
- `位置20`：最后一根封闭收盘价在最近 20 根高低区间中的位置，0 为最低、1 为最高。

这些量没有采用“小于某数就算能做”的门槛。固定 20 根只是统一观察尺，真正的结构起点仍需按前一段行情人工划分。

### 2.3 成交时间/价格一致性审计

额外检查每个开平仓事件：紧邻事件前完成的 15m K 线是否包含记录价格，容差为价格的 0.05%，用于兼容更细周期成交。

- 仅发现 `position-22` 开仓严重不一致：记录为 **2020-05-31 06:45、9,485.5**；紧邻的 06:30–06:45 15m K 线范围为 **9,531.57–9,740**，开仓价低于最低点 46.07 USDT。
- `position-25` 仅有 1.55 USDT 的小周期收盘差，在容差内。
- 因此 `position-22` 的收敛形态可以研究，但**精确入场触发和 MFE/MAE 不能据此确认**。它也不能用来证明“突破后只吃到一小段”。

## 四、关键对照：到底什么叫“收敛好了”

### 4.1 `position-25`：不是简单“20 根处于中部”，而是上涨后的高位保持

以 5 月 26 日低点约 8,623.38 到 5 月 31 日高点 9,753 为前一段上涨：

```text
入场前最后封闭 4H 收盘：9,541.71
保留下来的前段涨幅位置：(9,541.71 - 8,623.38) / (9,753 - 8,623.38) ≈ 81.30%
距离该段高点：约 2.17%
4H s20：0.45
```

如果机械地看最近 20 根 4H，最后收盘位置只有约 51%，容易误读成“区间中部”。但把窗口按前一段行情重新划分，会看到价格仍保住约八成涨幅，属于高位整理。

**这里的“收敛好了”应拆成：**

1. 前面有明确上涨；
2. 回调没有吞掉大部分涨幅；
3. 价格在高位形成可辨认的箱体；
4. 4H 区间明显收窄；
5. 入场后很快得到扩张确认。

第 5 条只证明执行结果，不是前四条的事后替代品。

### 4.2 `position-46` 与 `position-43`：同样的“小级别启动”，为什么一个值得研究、一个没逻辑

两笔在指标表面上很相似：4H 都比前段窄，1H 都开始扩张。差别主要在前段结构与位置。

| 观察项 | position-46 | position-43 |
|---|---:|---:|
| 4H s20 | 0.51 | 0.67 |
| 1H s20 | 1.55 | 1.58 |
| 最近 20 根 4H 内位置 | 约 80.9% | 约 50.9% |
| 距各自近期 4H 高点 | 约 0.31% | 约 1.22% |
| 结构解释 | 低波动筑底后，1H 连续转强并靠近短期上部 | 区间中部反弹，尚无明确方向偏向 |
| 合理结论 | 可列入“底部收敛后小级别启动”观察 | 只有反弹和横住，不能据此认定多头优势 |

**核心经验：小级别扩张只说明开始动，不说明往哪个方向有优势。** `position-43` 与 `position-46` 的相似指标不能代替位置和结构判断。

但也不要把 `position-46` 过度美化：它的更大背景是筑底与反转，不是“上涨后贴上沿”的标准延续形态。“主升开启”只能写在事后结果栏。

### 4.3 `position-1`：低波动指标否定收敛，几何结构却成立

`position-1` 的 4H `s20 = 1.76`，说明最近 20 根反而比前 20 根更宽。若把收敛等同“变安静”，它应被否决；但图上确实存在：

- 大幅下跌后的多次低点承接；
- 反弹、回踩、再反弹；
- 价格围绕关键区域反复测试。

所以这是**高分歧下的结构与边界收敛**，不是波动收缩。这个案例证明：不能用一个振幅指标覆盖你语言里的全部“收敛”。

### 4.4 `position-19`：小级别收敛成立，不等于大级别和入场位置都成立

`position-19` 的 4H `s20 = 1.19`，没有大级别收窄；1H `s20 = 0.73`，有局部收缩。入场前最后一根完整 1H 收于 9,392.85，而实际入场价为 9,494.5，说明入场所在小时已经上涨约 1.08%。

它的问题不是“完全没收敛”，而是：

- 收敛只在很小级别；
- 入场时已经反弹一段；
- 上方很快遇到约 9,596–9,622 的前高区域；
- 新入场的盈亏比与在收敛区内部买入不同。

最终几乎原价退出是合理风险控制，但这笔应标为「小级别收敛后跟随反弹」，不能只写“底部踩稳”。

### 4.5 `position-10 / 34`：收敛能提供位置，不能代替空头触发

两笔都在高位或相对高位做空，但入场前并没有同样清楚的向下结构确认：

- `position-10` 是高位箱体中的提前试空；
- `position-34` 只有 1H 明显收敛，4H 仍在宽幅波动，且入场后先继续逆向上涨。

它们最后盈利不能反推入场时已经有完整空头信号。更准确的标签应是「高位小级别收敛 · 提前试空」，并把上方失效位作为核心，而不是只写“收敛好了”。

### 4.6 `position-28 / 31`：真正的核心是假突破和反弹失败

这两笔共用同一条批注，图上也有相同的市场背景：

```text
大幅上冲 / 假突破 → 快速回落 → 小级别反弹 → 反弹停顿或结构转弱 → 空
```

这里“收敛”的作用是让反弹从推进变成可观察的停顿，给做空一个等待点；真正的方向证据是：

- 上方假突破或较低高点；
- 反弹无法继续；
- 小级别上涨结构被破坏。

如果只写“收敛空”，会丢掉最重要的做空原因。

## 五、把你的判断改写成一套可复用流程

### 第一步：先选结构模型，不要先找“安静”

至少分成三类：

| 模型 | 前段需要什么 | 位置与方向 |
|---|---|---|
| 趋势延续 | 一段清晰上涨/下跌，回调不能吞掉大部分推进 | 上涨后高位收敛看多；下跌后低位收敛看空 |
| 区间反转 | 明确箱体边缘、假突破或较低/较高点 | 上沿失败看空，下沿承接看多 |
| 底部/顶部反转 | 原有下降/上升结构缓和，低点抬高或高点下移 | 等结构破坏或小级别转强/转弱，不只看横盘 |

`position-25` 属第一类，`position-28 / 31` 属第二类，`position-13 / 46` 更接近第三类。三类不能用同一个固定窗口或一个 `s20` 阈值处理。

### 第二步：画出前段和位置，再谈收敛

盘前必须写清：

- 前一段行情从哪里到哪里；
- 回调吞掉了多少，是否仍保持大部分推进；
- 当前贴近哪条用户认可的压力/支撑/趋势线；
- 当前在结构边缘还是中部。

如果这一段写不出来，先不要下“收敛好了”的结论。

### 第三步：收敛允许多种形态，但必须指明是哪一种

- **箱体**：上下边界较平，价格仍在箱内；
- **低波动**：近期区间相对自身前段收窄；
- **三角/单边收敛**：高点下移或低点抬高，一条边成立也可以，不要求教科书式双边对称；
- **结构停顿**：反弹或回调开始横住，等待结构破坏。

振幅很大并不自动否定几何收敛；仅仅变安静也不自动构成交易机会。

### 第四步：把“入场方式”单独记录

| 入场方式 | 优点 | 主要风险 | 本批例子 |
|---|---|---|---|
| 收敛区内提前埋伏 | 价格好、失效近 | 方向尚未确认 | position-10 / 34 |
| 小级别突破时跟随 | 有启动确认 | 追价、遇前高、盈亏比变差 | position-19 |
| 突破后回踩/结构确认 | 兼顾确认与价格 | 可能不回踩，或回踩变反转 | position-22 因时点存疑无法归类 |
| 假突破后反向结构破坏 | 方向证据较强 | 需要等待，不是每次都有 | position-28 / 31 |

这四种不能都用“收敛突破”一笔带过。

### 第五步：先写失效位，再决定做不做

- 延续多：箱体下沿、回调低点或保留结构被破坏；
- 提前空：箱体上沿、假突破高点或最近反弹高点；
- 反转多：抬高低点被重新跌破；
- 小级别跟随：入场前最近小结构失效，而不是用更大级别无限扛单。

没有失效位时，“收敛好了”不能转化为仓位。

## 六、建议替换的标签与批注格式

### 6.1 标签应该区分结构与方向，不再只有「收敛短线」

| 原样本 | 更有信息量的命名 |
|---|---|
| position-1 | 宽幅承接收敛 · 反弹多 |
| position-7 / 25 | 上涨后箱体收敛 · 延续多 |
| position-13 | 下跌后底部收敛 · 反转多 |
| position-10 / 34 | 高位小级别收敛 · 提前试空 |
| position-28 / 31 | 假突破后反弹收敛 · 结构转弱空 |
| position-37 | 箱体内趋势线收敛 · 反弹多 |
| position-46 | 底部低波动收敛 · 小级别转强多 |
| position-19 | 小箱体收敛后跟随多 |
| position-43 | 有横盘、无方向边缘 · 不做 |

### 6.2 每次按五句话记录

```text
1. 前段：从 ___ 到 ___ 的上涨/下跌/假突破，结构是否完整。
2. 位置：目前在前段/箱体的 ___，方向偏向 ___；是否仍在区间中部。
3. 收敛：周期 ___，起止 ___，上沿 ___，下沿 ___，类型为箱体/低波/几何/停顿。
4. 触发：提前埋伏 / 突破跟随 / 回踩确认 / 结构破坏，具体 K 线为 ___。
5. 失效与目标：___ 失效，第一目标 ___，允许最大账户风险 ___。
```

有了这五句话，后续才能区分：

- 收敛看对但方向做错；
- 方向看对但入场太迟；
- 形态存在但没有位置优势；
- 入场合理但退出不合理。
