# redesign: box detection → volatility-based 收敛 (convergence)

## Goal

把 fractal 触碰式「箱体」检测换成**波动率驱动的「收敛」检测**——纯 bar 扫描平静平坦带，
绕开 fractal 触碰不足。8/12 07:15 起能扫出收敛（原为三角 0.855），8/13 00:30 三角保留。

## Requirements (已确认)

1. **收敛定义 = 波动率平静带**：滑动扫描每个可能的段起点，段须同时过：
   - **平边门（自适应）**：段内低/高点回归漂移 ≤ `flatRatio×coinVol`（coinVol = 窗口波动中位数）。
     相对该币自身波动缩放，跨币种/周期通用。区分 8/12（低点平，漂 0.34% vs coinVol 0.39%）
     与 8/13（低点抬 916→923，漂 0.7% → 拒）。
   - **收敛门（相对前段）**：段波动中位数 < `convergenceRatio ×` 前段**等长**段中位数
     （0.8）。内部尖刺被中位数吸收 → 允许尖刺。
   - **绝对安静门**：段波动中位数 < `0.8 × coinVol`——段必须真的低于该币常态波动，而非
     仅比临近尖峰安静。拒 8/13 尾巴、三角 fixture 的平尾巴（波动 ≈ 常态）。
   - **范围门**：当前价在段 [最低低点, 最高高点] 内（动态 min/max，容差 10%）。
   - **时长**：≥ `minRun`（5 根）。
2. **分数 = 相对安静 + 0.5×绝对安静 + 0.1×长度**，与三角分数比大小，**谁高谁赢**。
   8/12 长收敛（~0.97）压过假三角 0.855；8/13 短尾巴收敛（被绝对安静门拒）→ 三角 0.812。
3. **结构类型 `box` → `convergence`**，UI「箱体」→「收敛」。删除 fractal 箱体分支。
4. **三角检测保留**（fractal + backscanWindow 不变）。
