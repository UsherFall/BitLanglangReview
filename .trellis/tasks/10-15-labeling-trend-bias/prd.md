# 标注理由补「顺势」：判据从两轴扩到三点

## Goal

用户标了 33 只后把判据从两条轴扩成**三点结合**：**结构饱满 + 收敛 + 顺势**。要给标注页的理由集补上第三种情况，并把口径模板改成三点。

本任务只改**标注侧**（理由集 + 口径模板 + 记忆），**不动判据实现**——把「顺势」变成可计算量是 `structure-fullness` 的事。

## 触发 / 用户原话（2026-10-15）

> 「可能还要加个理由，我标了 33 只后发现有些前戏是差不多了，就是**结构饱满度差不多但还差个顺势**，所以我判断一个行情能不能做应该**三点结合**，一结构饱满、二顺势、三收敛」

追问「顺势指跟什么顺」时：

> 「和前一段大行情同向是对的，**但是**比如他前面一大段是跌下来，然后现在在下来后震荡的**箱体顶部收敛，那也是要去看多的**」

## 关键判断：名字与含义有落差（写进理由的描述里）

「与前一段大行情同向」盖不住用户的例子——跌完做多，是**逆**前一段。把四种情况摆齐后，共同点不是"顺前一段"，而是**收敛已经偏向一边、方向说得清**：

| 前面的大行情 | 收敛在箱体的位置 | 该看的方向 |
| --- | --- | --- |
| 涨完 | 贴上沿收敛 | 多（延续） |
| 跌完 | 贴上沿收敛 | **多（反转）** ← 用户的例子 |
| 跌完 | 贴下沿收敛 | 空（延续） |
| 涨完 | 贴下沿收敛 | 空（反转） |

用户说「我再想一下」，所以：**名字沿用他的原词「还没顺势」，描述写成"偏向"的实际含义**，不锁死；口径在标注过程中收敛。

## Requirements

- **R1 理由集加一项**：`前戏不足 / 收缩没到位 / 还没顺势 / 就是好 / 其他`。数字键扩到 `1`-`4`，`0` 清空。
- **R2 口径模板改成三点**：`label-rubric.md` 的「三句话」按 结构饱满 / 收敛 / 顺势 重写，并把上面那张四情况表放进「教具卡片」旁边，作为"顺势"的操作性说明。
- **R3 理由表补一行**：写清「还没顺势 = 这段收敛没偏出方向，看不出该做多还是做空」，并标注"口径待定"。
- **R4 已标 33 只的完整性提示**：口径模板里留一句提醒——若早前的标注把"只是没顺势"记成了「就是好」，那几条需要回看。**不自动改数据**。
- **R5 不动判据**：不改 `src/domain/coin-scan.ts`，不改采样与快照逻辑。
