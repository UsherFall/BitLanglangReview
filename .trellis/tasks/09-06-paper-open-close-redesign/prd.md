# 回溯复盘开平仓交互重构

## Goal

让 Free Replay 模拟盘的开/平仓交互贴合真实交易者心智，去掉把内部批次（leg）会计结构当主操作面造成的杂乱：
- **每个开仓批次 = 一个独立逻辑**，各自带止损（一仓一损），可设/移/删；
- **平仓是整仓级操作**：整仓平 X%（FIFO 跨批次）或全平；不做逐仓手动平仓；
- 界面按"一个头寸 + 整仓比例平仓 + 各批独立止损"组织。

## Background（2026-09-06 brainstorm 结论）

- 用户口径：*"分批止损的功能是要的，我每一个开仓的逻辑都是独立的所以每一个仓都会设一个止损，但也会在某个时候把整仓平一部分或者全平"*。
- 已推翻旧决策（`09-02` 曾确认"手动平仓按仓操作"）：**平仓改为整仓级比例/全平**，逐仓行只做止损管理。
- 逐仓行平仓比例/按钮是我上轮的误修（用户反馈"修得不好"），本任务移除。
- 代码事实（domain `free-replay-paper-trading.ts`）：
  - `closeMarket(session, candle, eventTime, ratio)` 已存在 = 整仓 FIFO 比例平仓，十余个测试覆盖；
  - `closeQuantityFor` FIFO 自最早 leg 起扣；部分消耗保留该 leg 及其 `stopPrice`，整 leg 耗尽则连止损移除；legs 空则 `position=null, pendingExit=null`；
  - `closeLegMarket`（逐仓手动平）仅被 UI 与 2 个测试引用 → 移除（语义可用 `closeMarket(ratio)` 等价表达：单仓=该仓；等量多仓 50%=整删最早一仓）。

## Requirements

### R1. 逐仓止损行（纯止损，不含平仓控件）
- 每仓一行：仓序号、开仓价、剩余数量 + 止损价 input + 设止损/改价 + 删除。无数量输入（止损自动覆盖该仓剩余）。无平仓比例、无平仓按钮。

### R2. 整仓级市价平仓（FIFO，单个按钮 + 可选比例）
- 平仓区一个「平仓比例」控件（25/50/75/100，默认 100；每次提交后复位 100）。
- 单个「市价平仓」按钮：`closeMarket(ratio)` 整仓 FIFO 减 X%。**没有独立的"全部市价平仓"按钮**——X=100 即全平（legs 空 → position/止损/止盈挂单一并清除），X=50 即"平半仓"。一键全平 = 默认/复位后的 100 直接点按钮。
- 该按钮同时承担用户"平一部分"与"全平"两个手势，靠比例控件区分。

### R3. 全局限价止盈（单档，行为沿用）
- 价格输入 + 提交：`quantity = 当前持仓 × 平仓比例`，固化 ≤ 持仓，触达 FIFO 成交，成交后移除。「平仓比例」与 R2 共用同一控件（一个 % 意图，市价或限价两种出口）。

### R4. 开仓/加仓（不变）
- 空仓市价/限价开仓；有仓同向加仓产生新 leg（保证金 = 仓位比例 × 可用，可用 0 阻止）；方向锁定。每个新 leg 止损在逐仓行独立设置，不自动继承。

## Acceptance Criteria

- [ ] 逐仓行只含止损管理（设/移/删），无平仓比例/平仓按钮。
- [ ] 单一「市价平仓」按钮按当前平仓比例整仓 FIFO 减仓；比例选 50 平两等量仓 = 整删最早一仓，其后该仓止损不触发（回归）。
- [ ] 比例选 100（或复位后默认）市价平仓 = 全平，止损不再触发、止盈挂单清除（回归）。
- [ ] 部分消耗一个 leg 后，该 leg 剩余仍带原止损，触发只平剩余。
- [ ] 逐仓止损触发行为不回归（单仓止损只平该仓；同根 K 线多仓各按价位成交）。
- [ ] 加仓/保证金/方向锁定行为不回归。
- [ ] domain 测试更新并通过；`closeLegMarket` 及其 2 个逐仓平测试删除或改写为 `closeMarket(ratio)` 等价语义。

## Out Of Scope

- 多空并发/反手/对冲；手续费/资金费/滑点/强平。
- 阶梯止盈（多档限价止盈挂单）。
- 逐仓选择性手动平仓（用户口径为整仓级平仓）。
- 图表绘制挂单价格线。

## 关键决策记录

- 整仓 X% 平仓分配：**FIFO**（先平最早仓；用户已确认，2026-09-06）。
- 比例控件：市价平仓与限价止盈共用**一个**「平仓比例」，避免 % 控件散落。
- **单一「市价平仓」按钮**承担平一部分（X<100）与全平（X=100），不设独立"全部市价平仓"（用户 2026-09-06）。
- **取消逐仓手动平**：UI 与 domain（`closeLegMarket`）一并移除（用户 2026-09-06）。
