# 优化主升浪候选指标表达

## Goal

让使用者不看算法文档，也能理解「主升浪候选」为什么列出某个标的、表格数字代表什么，以及画线距离状态该如何解读；同时避免把候选项误解为已经启动或自动买点。

## Confirmed Facts

- 主要问题集中在 `src/ui/CoinScanPanel.tsx`：左侧说明直接出现「池内分位粗筛 / 净漂移 / 序列绝对底部」，结果单元格使用「区间 / 净 / 位」，距线详情使用「该币尺子 / 倍数」。
- 结果摘要当前先显示 `粗筛 result.scanned.length`，再显示 `候选 coarse.candidates`，但实际过程是先扫描候选池、再得到符合条件的行，现有名称和顺序都不直观。
- `src/domain/coin-scan.ts` 与 `.trellis/spec/server/coin-scan.md` 确认：`rangePct` 是最近 23 根日线的振幅，`netPct` 是同一窗口首尾收盘价的绝对变化，`posRange` 是现价在本次读取的日线序列中的位置。
- 「位 = 全部历史里的位置」不准确：本次只读取一段日线序列，通常最多约 100 根，Bitget 还可能更少；优化文案时必须修正，不能沿用“全部历史”。
- `src/domain/level-alert.ts` 确认：距离正负表示现价在线上方或下方；典型波动是该周期单根 K 线振幅的中位数；`≤0.5` 倍为贴近、`>0.5 且 ≤1` 倍为接近、其余为远。

## Requirements

### R1. 首屏先解释用途，不先讲算法

- 保留方法名「主升浪候选」，在参数区给出简短中文说明：寻找最近 23 根日线振幅较小、首尾变化不大，且不贴近近期低位的品种。
- 明确提示：结果只是横盘候选，不代表已经启动，也不自动判断买点；画线距离用于后续观察。
- 删除首屏大段内部术语，不再要求用户理解「池内分位 / 净漂移 / 序列绝对底部」才能使用扫描。
- 保留扫描范围、数量上限、成交额、历史时间点和休市规则等必要操作说明，但应拆分阅读，避免继续组成一段长文。

### R2. 结果摘要按实际筛选顺序表达

- 摘要按「扫描候选池数量 → 符合横盘条件数量 → 靠近画线数量」的顺序展示。
- 使用「扫描 N 个 → 符合横盘条件 M 个 · 靠近画线 K 个」一类明确措辞，不再使用含义倒置的「粗筛 M 个 · 候选 N 个」。
- 保留默认显示 20 行、展开/收起、异常标的提示等现有行为和计数口径。

### R3. 表格与详情使用可理解的指标名

- 「结构」改为能概括日线表现的名称；单元格中的「区间 / 净 / 位」分别改为「23 日振幅 / 23 日变动 / 历史价格位置」，窗口天数随响应值变化。
- 「距线」明确为「离我画的线」，让使用者知道测量对象来自自己的画线。
- 详情中的「该币尺子 / 倍数」改为「近期典型波动 / 相当于几倍波动」一类直白名称；说明正数在线上方、负数在线下方。
- 状态文案统一为「很近 / 较近 / 还远」，对应现有 `alert / watch / far` 三档，不改变阈值、排序或 `alertTimeframes` 计数。
- 不改变价格、涨跌幅、成交额、操作按钮和画线徽章的含义。

### R4. 详细口径可主动打开，不只依赖 hover

- 在结果区提供一个无需 hover 即可展开的「指标怎么算？」说明区。
- 说明区至少解释：
  - 23 日振幅：最近 N 根已完成日线的最高价至最低价跨度，包含影线；越小越窄。
  - 23 日变动：同一窗口首尾收盘价的绝对变化；越小越接近横盘。
  - 历史价格位置：现价在本次读取的日线序列高低点之间的位置，0% 靠低位、100% 靠高位；不是全部历史。
  - 振幅和变动的通过门槛随当前候选池重新计算，位置下限仍用于排除贴底标的；保留本次实际阈值的查看方式。
  - 近期典型波动及三档画线距离：很近不超过 0.5 倍、较近在 0.5 至 1 倍之间、还远超过 1 倍。
- 「标线监控」没有日线粗筛数据，不得出现候选池、横盘条件或日线指标说明。

## Acceptance Criteria

- [x] AC1：主升浪候选参数区能看到简短的用途说明和“候选不等于启动/买点”的提示，首屏不再出现「池内分位粗筛」「净漂移」「序列绝对底部」等内部术语。
- [x] AC2：结果摘要以扫描池到筛选结果的顺序展示；对 465 个候选、2 个结果、1 个贴近行的响应，能读出「扫描 465 个」「符合横盘条件 2 个」「靠近画线 1 个」。
- [x] AC3：日线单元格直接显示「23 日振幅」「23 日变动」「历史价格位置」及原数值，不再显示缩写的「区间 / 净 / 位」。
- [x] AC4：画线列和详情明确指向用户自己的画线，详情能看懂典型波动、距离倍数、正负方向和三档状态；三档阈值与原逻辑一致。
- [x] AC5：不 hover 也能展开指标说明；说明包含各指标含义、动态门槛及位置序列边界，且不再声称位置来自“全部历史”。
- [x] AC6：标线监控仍不显示粗筛指标和候选池说明；现有扫描请求、筛选算法、距线计算、排序、降权、20 行截断及异常提示行为不变。
- [x] AC7：更新并通过 `tests/coin-scan-panel.test.tsx`、`tests/coin-scan-results.test.tsx`，再运行完整测试、TypeScript 检查和 `git diff --check`。

## Out of Scope

- 不修改 `src/domain` 或 `src/server` 的筛选、阈值、排序、距线和 API 数据契约。
- 不重新命名「主升浪候选」方法，不新增自动买卖点、趋势预测或文字诊断。
- 不调整表格列数、操作按钮体系、扫描参数默认值或其他扫描方法。
- 不处理与本次无关的历史乱码、测试运行器配置或全局样式重构。

## Key Decisions / Risks

- 采用“首屏用途说明 + 直白指标名 + 可展开详细口径”的渐进披露，而不是继续增加 hover 长文。
- 保留实际数字和阈值查看入口，优化表达不等于隐藏计算依据。
- 「历史价格位置」必须在详细说明中限定为“本次读取的日线序列”；若未来需要精确展示实际根数，应另补数据字段，不在本次猜测固定 90 或 100 天。
