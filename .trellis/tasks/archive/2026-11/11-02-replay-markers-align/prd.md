# 回溯复盘开平仓标记对齐交割单复盘 + 会话切换面板跟随

## 背景

用户报告回溯复盘（freeReplay 模式）四个问题。调查结论（2026-11-02，基于 data/review.sqlite 中 BTCUSDT 2023-03-18 会话的实测数据）：

1. **眼睛按钮语义不对**：「隐藏开平仓标记」当前是全隐藏（`setMarkers([])`）。用户期望与交割单复盘一致：隐藏其他单子、只保留当前选中（焦点）单。
2. **开平仓点位跨周期错位**：缓存 K 线与币安官方数据逐根比对完全一致（1H/15m 625+ 根 OHLC 无差异、无缺口）——不是数据错误。错的是 `paperTradeMarkers` 用 `freeReplayCursorTimeForProgress`（完成时间→光标K线）反推标记位置，该映射只对「在当前图表周期上做的单」成立。用户在复盘中途切 15m/5m 做单后切回 1H 查看，30 笔成交约 20 笔的标记整体左移一个粗周期 K 线（例：15m 蜡烛 23:20-23:35 的成交在 1H 图上标记落在 22:00），挂在与成交价完全对不上的 K 线上，看起来像「K线加载错误、点位错误」。
3. **标记 UI 与交割单复盘不一致**：回溯复盘用 lightweight-charts 内置 SeriesMarker（箭头 + "开 xxx" 文字）；交割单复盘用 `TradeMarkerPrimitive` 画布圆点 + 悬浮卡片（价格/数量/时间/杠杆/盈亏）。用户要求统一为后者。
4. **会话切换后单子 tab 不跟随**：从 2023.5 BTC 会话切到 2023.3 后，单子 tab 没跟着换。当前代码两条针对性复现测试（真实库 payload + flush 时序）均通过，疑似用户当时浏览器挂着重启前旧代码；但该路径缺少回归测试，且面板本地状态（panelTab/方向/限价输入/平仓比例）跨会话残留没有重置机制，需要根治。

## 需求

### R1 眼睛按钮 = 只留焦点单

- FreeReplayChart 工具栏的「隐藏开平仓标记」按钮：隐藏的是**除当前焦点单（orderFocus 指向的单子行）以外**的所有开/平标记，行为对齐交割单复盘「默认只显示当前交易」的语义。
- 焦点为空时点击：全部隐藏（无选中单子，等价于没有可保留的标记）。
- 再点一次恢复显示全部。
- 按钮文案/图标沿用现有（Eye/EyeOff）。

### R2 标记锚定到包含成交时刻的已加载 K 线

- 每笔 paper 成交（开=positionOpenTime，平=exitTime，均为「完成时刻」）的标记必须锚定到**包含该成交时刻的已加载 K 线**：即包含 `(完成时刻 - 1ms)` 的那根蜡烛（成交发生在源蜡烛收线的瞬间）。对「同周期做的单」等价于现有光标蜡烛；对「细周期做的单切粗周期看」落在正确的粗蜡烛上；对「粗周期做的单切细周期看」落在粗蜡烛收盘所在的那根细蜡烛。
- 交割单复盘同款规则：用 `containingCandleTimestamp` 对齐已加载蜡烛；没有已加载蜡烛包含它就不画（滚入视口后自然出现）。
- 不再用 `freeReplayCursorTimeForProgress`（progress→cursor 映射）反推标记时间，不用 grid 取整（shanghai/utc）猜测蜡烛位置。
- 修复后：1H 图上 BTC 2023.3 会话所有成交的标记蜡烛 close 必须与成交价一致（可据此写回归断言）。

### R3 标记 UI 与交割单复盘一致

- 回溯复盘弃用 `createSeriesMarkers` 内置箭头标记，改用 `TradeMarkerPrimitive`（画布圆点：开=实心、平=空心环；多空配色沿用 `pointColor`；挂在蜡烛上方/下方规则同交割单复盘）+ `createTradeMarkerTooltip` 悬浮卡片。
- tooltip 内容：价格、数量、时间、杠杆、（平仓点）盈亏。来源（市价/限价/止损市价）若 paper 成交数据有对应字段则显示，否则省略该行。
- 保留现有按钮：重置价格刻度、对数价格刻度；眼睛按钮语义按 R1 改。
- 未来 K 线不揭示的现有约束（`visibleCandlesForFreeReplay`、标记 `<= cursorTime` 过滤）必须保持——标记层换实现后，揭示前不得显示任何未来标记。

### R4 会话切换后面板跟随

- 从历史会话切换（onRestore）到另一个会话时，模拟交易面板整体跟随新会话：单子列表、持仓、待挂单、统计全部来自新会话。
- 面板本地状态（panelTab、方向、仓位比例、杠杆、限价输入、平仓比例）在切换会话时重置，不跨会话残留（通过按会话身份 key 面板或等价手段）。
- 补回归测试：恢复会话 A → 切换恢复会话 B，断言单子 tab 显示 B 的单子。

## 验收标准

- [ ] 回溯复盘开平仓标记为画布圆点 + 悬浮卡片，视觉与交互与交割单复盘一致（同 primitive、同 tooltip 结构）。
- [ ] 点「隐藏开平仓标记」后：有焦点单 → 只显示该单的开/平两个点；无焦点 → 无标记。再点恢复全部。
- [ ] BTC 2023.3 场景（跨 15m/5m/1H 做单）：1H 图上每笔成交的标记蜡烛 close == 成交价（回归测试用真实错位模式覆盖：细周期成交在粗周期图上不错位）。
- [ ] 标记未滚入已加载范围时不画、滚入后出现；未来 K 线（> cursor）不画任何标记。
- [ ] 历史会话 A→B 切换后：单子 tab 内容、持仓、统计、面板本地状态全部来自 B（回归测试覆盖）。
- [ ] `npm test` 全绿；app-free-replay.test.tsx 中依赖旧箭头标记（setMarkers/text 断言）的用例改造成断言 primitive 点集。
- [ ] 不改动交割单复盘（TradeChart）的任何行为。

## 范围外

- 交割单复盘自身的行为/样式调整。
- paper trading 交易撮合逻辑、K 线数据源/分页（10/21、10/30 契约）不变。
- 不做「显示全部开平仓」（MapPin）按钮的回溯复盘版（用户未要求；焦点过滤已覆盖需求）。
