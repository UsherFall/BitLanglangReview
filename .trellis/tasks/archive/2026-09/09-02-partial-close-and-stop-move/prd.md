# 模拟盘支持分批平仓、移动止损、加仓与"一仓一损"止损

## Goal

让 Free Replay 的模拟交易贴近真实分批操作：
- 到目标位置只平掉剩余仓位的一部分，剩余继续持有；手动减仓仍按整体剩余比例（FIFO）。
- 释放的保证金可同方向加仓，形成"合并均价仓"（内部按批次 legs 记录，展示总数量/均价/总保证金）。
- 每个开仓批次（首开 + 每次加仓）对应一个自己的止损（**一仓一损**），止损数量自动等于该仓剩余数量，无需手动输入数量；触发时只平该仓。
- 单一全局限价止盈挂单保持固定数量。
所有操作随 K 线推进即时反映在持仓、收益、成交列表与图表标记上。

## Background

- 模拟盘逻辑在 `src/ui/free-replay-paper-trading.ts`，UI 在 `src/ui/App.tsx` 的 `FreeReplayPaperTradingPanel`，测试在 `tests/free-replay-paper-trading.test.ts` 与 `tests/app-free-replay.test.tsx`。
- 模拟状态随 Free Replay session 以不透明 JSON 自动保存，DB 里可能已有多个历史形状（单块仓 → legs → 旧挂单式止损），恢复需归一化。
- 不变：已揭示 K 线不回溯触发；挂单只由后续 reveal 触发；ArrowLeft rewind 不回滚模拟交易状态。

## Confirmed Decisions（最终模型）

- 持仓为合并均价仓：每个开仓批次（首开/加仓）是内部的一个 leg；展示总数量、剩余批次的加权均价、总保证金。
- **每仓一个止损**：止损挂在 leg 上（`leg.stopPrice`），数量自动 = 该仓剩余数量；一个仓最多一个止损；可对单仓改价（移动/跟进）与删除；改价不改数量。
- 止损触发只平该 leg 本身（按其剩余数量、该仓成本成交），其他 leg 不动；leg 平完止损随 leg 消失。
- **手动平仓按仓操作**：每个仓行内有「市价平 X%」按钮（对该仓自己减，X 默认 100=整仓平掉）；同时保留「全部市价平仓」一键清仓（清除所有仓与挂单）。"平半仓"在多仓等量场景即"平掉其中一个整仓"。
- 限价止盈为**单个全局挂单**（同类替换），挂单时固化数量（≤ 当前持仓），触发按 FIFO 成交（数量不足按剩余成交）。
- 止损价位不限制开仓价侧，只要求方向合理（多单止损 < 当前 K 线价、空单 > 当前 K 线价）。
- 已完成交易按每次平仓动作一行；统计/胜率按平仓笔数；图表每个平仓点一个标记、同一轮开仓只一个开仓标记。
- 单方向单合并仓：多空不能同时持有；方向在持仓存在时锁定。

## Requirements

### R1. 手动平仓（按仓 + 一键全平）

- 持仓区每仓行有「市价平 X%」（X=平仓比例控件，默认 100%，快捷 25/50/75/100），对该仓减仓：全平该仓或平该仓 X%。
- 提交后平仓比例复位 100%。平掉某仓整仓时该仓止损自动消失；部分平则剩余部分仍带止损。
- 「全部市价平仓」按钮：整仓一键全平（FIFO 汇总成交）并清除止损与限价止盈挂单。
- 限价止盈挂单 X%：固化 `quantity = 当时剩余 × X%`（≤ 持仓），触达按 min(quantity, 当时剩余) FIFO 成交；成交后移除、比例复位 100%。

### R2. 加仓

- 释放的保证金可同方向开仓（加仓，方向锁定）；每笔保证金 = 仓位比例 × 当前可用（可用 = 1000 − Σleg 保证金）；可用为 0 阻止。

### R3. 一仓一损（逐仓止损）

- 持仓区列出每个仓（leg）：序号、开仓价、剩余数量，以及该仓的止损编辑（止损价 + 设止损/改价/删除）。
- 数量**不需要输入**：止损永远覆盖该仓当前剩余。
- 每仓止损触发：`low <= stop`（多）/ `high >= stop`（空）时，按该仓剩余数量、该仓开仓成本成交，生成一行平仓记录，该 leg 移除。
- 同根 K 线穿破多仓止损 → 各仓按各自价位成交。
- 手动减仓不会撤销未触发仓的止损；仅当该 leg 数量归零时 leg（含止损）消失；整仓清空清除全局止盈挂单。

### R4. 持仓展示

- 聚合摘要：方向、均价、数量、保证金、可用、浮盈。
- 逐仓列表（含各仓止损状态）。
- 限价止盈挂单 chip（待平仓 price）。

### R5. 平仓记录与统计

- 每次平仓动作一行（含手动比例平、限价止盈成交、单仓止损成交）：方向、FIFO/该仓开仓成本、平仓价、时间、数量、保证金、PnL、收益率。
- 已实现 PnL / 总收益率 / 胜率 / 盈亏比 / 交易数按平仓行计算。

### R6. 图表标记

- 每笔平仓动作一个平仓标记；同一合并仓位只一个开仓标记（按 positionId）。

### R7. 兼容已保存会话

- `normalizePaperTradingSession`：旧单块仓 → 单 leg；旧单独止损对象/旧挂单式止损列表 → 按 leg 顺序挂到对应 leg（尽力迁移，按创建时间排序逐个分配）；止盈单缺数量按持仓×比例估算；无 leg 时旧止损丢弃。

## Acceptance Criteria

- [ ] 每个仓行可「市价平 X%」对该仓减仓：整仓平则该仓止损消失、剩余继续持有；部分平则该仓剩余仍带止损；提交后比例复位 100%。
- [ ] 加仓产生新仓（leg），与旧仓各有独立止损；触发各自价位各平各仓。
- [ ] 每仓止损设置不需输入数量（自动=该仓剩余）。
- [ ] 单仓止损可改价（移动止损）与删除；改价不改数量。
- [ ] 止损可设在开仓价盈利侧，只需方向合理。
- [ ] 同一根 K 线穿破多仓止损时各仓按各自价位成交。
- [ ] 「全部市价平仓」一键清仓，之后不再触发任何止损（回归）。
- [ ] 限价止盈单个全局、固定数量、数量不超过持仓；整仓缩水后触达按剩余成交。
- [ ] FIFO 已实现盈亏与剩余均价正确（含跨批次手动平仓）。
- [ ] 已完成交易按每次平仓动作一行、统计与行一致；图表平仓点标记、同轮开仓标记一次。
- [ ] 恢复历史旧形状 session 不崩溃，止损尽力迁移。
- [ ] domain 测试覆盖并通过；jsdom 用例与既有流程按新交互更新（本机环境问题另行处理）。

## Out Of Scope

- 多空并发、反手、对冲；手续费/资金费/滑点/强平；导出正式 Trade；本金复利。
- 阶梯止盈（多档限价止盈挂单）——止盈保持单档全局。
- 图表绘制挂单价格线。
