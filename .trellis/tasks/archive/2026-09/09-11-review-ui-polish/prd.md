# 复盘/选币界面视觉与标注优化

## Goal

改善「交割单复盘 / 个人交割单复盘」与「选币」两个模块的浮层布局与图表标注：

1. 龙头币面板从左上角移到右上角，并与同样位于右上角的「其他币」「热度」浮层自动错开堆叠，互不遮挡。
2. 「其他币」K 线图上标注出当前复盘单**开单那根 K 线**的位置（与主图开单时刻时间对齐）。
3. 「选币 · 收敛结构」结果页里「已跳过 N 个休市标的」提示当前会撑出一大块空白，需消除空白但保留该行文字。
4. 「选币 · 热度」扫描结果目前套用浮动小窗样式，飘在右上角、与页面不搭，需改为页面内嵌样式。

## Background

- `OtherCoinChart` 是「其他币」按钮打开的浮层组件，`交割单复盘`(trade) 与 `个人交割单复盘`(bitget) 两个模式共用同一分支渲染（`src/ui/App.tsx:775`、`src/ui/App.tsx:790`），因此标注只需改一处。
- 三个浮层由 `detail-header` 里的独立开关控制，可同时打开：`.other-coin-panel`(右上)、`.market-heat-panel`(右上)、`.leader-coin-panel`(左上，styles.css:700)。
- `select / leader / heat` 浮层均为 `position:absolute`，不作为 `.workspace`(grid) 的网格项。
- 选币「收敛结构」空白根因：`.workspace` 为 `grid-template-rows: auto minmax(360px,1fr) auto`(styles.css:567)，`CoinScanResults` 在无/有跳过提示时分别返回 2 / 3 个子元素；有提示时该 `<p>` 落入 `1fr` 行被撑高。
- 热度结果 `HeatScanResults` 复用 `.market-heat-panel`（`position:absolute; top:76px; right:18px; width:420px`），并无 `.heat-scan-results` 样式，故表现为浮动小窗。

## Requirements

- R1 龙头币浮层显示在右上角；当「其他币」「热度」「龙头」中任意多个同时打开时，按固定顺序在右上角纵向堆叠、互不遮挡，并保证在可视区域内可用。
- R2 「其他币」K 线图在开单时刻对应的那根 K 线上叠加一条**淡色竖直参考线**（无文字标签）；随缩放/平移/切换币种/切换周期/加载更多 K 线保持对齐。
- R3 「选币 · 收敛结构」的「已跳过 N 个休市标的：…」文字并入标题统计行下方展示，不再产生大块空白，表格区域正常占据剩余空间。
- R4 「选币 · 热度」结果改为页面内嵌区块，视觉上与选币页其余部分一致：温度读数横排于顶部，涨幅榜与跌幅榜**左右两栏并排**；浮动小窗形态（复盘头部「热度」按钮）保持不变。

## Acceptance Criteria

- [ ] AC1 打开「龙头」浮层，其出现在内容区右上角；同时打开「其他币」「热度」，三者纵向排列且无重叠。
- [ ] AC2 在「其他币」浮层选任一币种，图上出现一条淡色竖直参考线，位置与该币在开单时刻（按当前周期对齐到 K 线）一致；放大/缩小/左右平移后参考线仍对齐同一根 K 线。
- [ ] AC3 「选币 · 收敛结构」结果页在存在跳过标的时，标题下方显示「已跳过 N 个休市标的：…」，且不再出现被撑高的大块空白；表格正常填充。
- [ ] AC4 「选币 · 热度」结果占满内容区、样式与页面一致（顶部温度读数 + 涨幅榜/跌幅榜两栏并排）；复盘头部点开的「热度」仍为浮动小窗。
- [ ] AC5 `npm test` 全部通过。

## Out of Scope

- 不新增/修改任何后端接口与领域逻辑（`src/server`、`src/domain`）。
- 不改变「其他币」浮层仅支持单币种展示的交互模型。
- 不新增参考线的开关/标签/数值展示（本次仅淡色竖线）。
- 不改动主复盘图已有的开平仓标记与画线逻辑。

## Key Decisions

- D1 右上方三个浮层采用「右上角锚定 + 纵向 flex 堆叠」实现自动错开，而非固定 top 偏移级联。（来源：用户选择「自动错开堆叠」）
- D2 「其他币」开单标注采用「仅淡色竖直参考线、无标签」。（来源：用户选择）
- D3 「已跳过休市标的」提示并入标题统计行下方展示。（来源：用户选择）
- D4 热度内嵌结果采用两栏并排版式。（来源：用户选择）
