# 选币模块(缩量方法 V1)

## Goal

在本地复盘网站(Trading Review)中新增一个**独立"选币"模块**,用各种方法从 OKX 合约市场找币,辅助选币/复盘。V1 只实现**缩量**方法,模块框架按"可插多个找币方法"设计。界面全中文。

## Background

- 网站为本地单用户期货复盘工具,数据源 **OKX 公开行情**。
- 现有模式:`Trade Review`(Excel 交割单复盘)、`Free Replay`(OKX 任意币任意时间复盘)。
- 全局 skill `bit-scan` 是终端选币系统(币安数据),与本网站不互通;本模块走 OKX,是网站的"选币"入口。
- 用户已明确:网站现有英文界面中文化另立任务,不在本任务内。

## Requirements

| ID | 需求 |
|----|------|
| R1 | 数据源 OKX。复用现有 `candlestick-service`(含本地缓存)、OKX SWAP 合约列表基础设施。 |
| R2 | 独立"选币"模块,与 Trade Review / Free Replay 平级(新 tab)。通用找币框架,`method` 可插;V1 仅 `shrink`(缩量)。 |
| R3 | 扫描范围:OKX SWAP 中 **USDT 结算**(instId 含 `-USDT-SWAP`),按 **24h 成交额 Top-N** 筛选;N 前端可调(默认 50)。 |
| R4 | 扫描参数全前端可调:**时间周期**(默认 `5m`,可选 `5m/15m/1H/4H/1D`;1m 被领域规则排除)、**量比阈值**(默认 0.7)、**连续缩量根数 M**(默认 3)、**均量窗口**(默认 20)。 |
| R5 | 缩量算法:量比 = 单根成交量 / 前 N(均量窗口)根均量;缩量强度分 = 最近 M 根量比均值;合格 = 最近 M 根量比全部 < 阈值。只用**已收盘** K 线(排除未走完的当前 bar)。 |
| R6 | 展示:**全量排名表**,扫描的 N 个币全部按缩量强度分升序(缩得最狠在前),合格币高亮/置顶。列:币、最新价、24h 涨跌幅、当前量/均量/量比、强度分、连续缩量根数。 |
| R7 | **手动扫描按钮**,无自动定时刷新。 |
| R8 | 点击结果行 → 跳转 Free Replay 图表查看该币,使用扫描所用时间周期。 |
| R9 | 新模块界面全中文。 |

## Acceptance Criteria

- [ ] AC1:侧边栏出现平级于 Trade Review / Free Replay 的"选币"tab,界面全中文。
- [ ] AC2:参数面板含时间周期 / Top-N / 量比阈值 / 连续根数 / 均量窗口;默认值 5m / 50 / 0.7 / 3 / 20;均可修改。
- [ ] AC3:点"扫描"后返回 Top-N 币按强度分排序的列表;合格币(连续 M 根量比 < 阈值)高亮区分。
- [ ] AC4:结果表列齐全:币、最新价、24h 涨跌幅、当前量、均量、量比、强度分、连续缩量根数。
- [ ] AC5:点击某行 → 切到 Free Replay 并加载该币在所选周期的图表。
- [ ] AC6:扫描 K 线经现有 candlestick 缓存复用;逐币拉取串行限频,不撞 OKX 限制。
- [ ] AC7:扫描失败(OKX 不可达)返回可读错误,UI 显示加载失败不崩溃。
- [ ] AC8:核心算法有单元测试(量比 / 强度分 / 合格判定 / 排序)。

## Out of Scope

- 自动定时刷新(R7 反向)。
- 网站现有英文界面中文化(另立任务)。
- 其它找币方法(放量、突破、金叉等)及其它时间周期外的周期。
- 全市场扫描(非 Top-N 限定范围)。
- 结果持久化/历史扫描记录。
