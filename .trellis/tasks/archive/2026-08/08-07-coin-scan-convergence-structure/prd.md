# 选币模块-收敛结构检测(三角/低波动箱体)

## Goal

改造选币模块的「缩量」方法,升级为**收敛结构检测**:找出当前处于**收敛三角**(高点下移 + 低点上移,趋势线收敛)或**低波动箱体**(水平通道、振幅相对自身收窄、无方向漂移)的币。两类结构都代表"蓄力待突破"。方向不锁定(多头空头都选)。

## Background

### 当前机制诊断(为何改造)

当前「缩量」方法本质 = **波动率收缩探测器**:compression(近期振幅/前期振幅) + latestTrend(还在收窄) 双门,纯相对比值,无结构验证(`src/domain/coin-scan.ts` 的 `computeQuietMetrics`/`computePlateau`)。缺陷:

1. 短周期(5m/15m)数据窗太短(固定 13 根 = 65min),瞬时安静段当收敛。
2. 相对压缩 ≠ 绝对收敛:0.9% body 的币仍可过门。
3. bw=3 时 latest-trend 窗口塌陷(comp==lt),门变单条件。
4. 只测"振幅在缩",不验证结构 —— 三角、箱体、下跌中继不区分。

### 已定设计决策

1. **结构识别深度 = 完整 swing 验证**:fractal swing 高低点识别,三角/箱体都从 swing 结构判。不用统计近似。
2. **绝对振幅不做门**:不同品种振幅天然不同,绝对阈值误杀天然振幅大的品种。改用**相对自身**:箱体"低波动" = 箱体高度相对该币自身前期波动收窄。天生安静的币(compression ≈ 1)被拒 —— 没有"从大波动收敛到小"的过程,不是蓄力。
3. **探测型窗口 = swing 定窗口**:swing 高低点间距 = 结构跨度,窗口从结构量出来,不预设固定窗口。盘整大 → swing 间距大 → 自动用大窗口。
4. **swing 定义 = 探测型 N fractal(候选 N 扫描)**:在候选 N = [2,3,4,5,6,8,10,12] 上全试,选产出最规整结构的 N(有结构 > 触碰多 > swing 对数多 > score 强)。每个币每周期独立探测到自己的结构尺度,小盘整小 N 显形、大盘整大 N 显形。
5. **集成方式 = 改造现有 shrink 方法**:不新增 method,把压缩机制升级为结构检测。
6. **结果表列 = 结构类型(三角/箱体)、结构内位置、收敛强度分**。不保留旧压缩比/收窄趋势/plateau 列。
7. **UI 参数面板 = 极简**:只留扫描数量、最低成交额、扫描时间点 + 一个「结构强度阈值」主旋钮。swing N、触碰次数、斜率容差等内部自适应或固定最优值,不暴露。
8. **保留全周期扫描**:每周期(5m/15m/1H/4H/1D)单独判定结构,一币一行,列出各周期结构。覆盖"小盘整成长为大级别"的演化。

### 结构定义(已定)

**收敛三角**:
- 高点逐波下移 + 低点逐波上移(或一边平 = 上升/下降三角)。
- 趋势线收敛(两线往一点走)。
- 各边至少 2 次触碰。

**低波动箱体**:
- 水平通道:swing 高点、低点各自回归,斜率 ≈ 0(无方向漂移)。swing 点回归斜率容差内视为水平。
- 幅度相对自身收窄:箱体高度相对该币自身前期波动收窄。
- 水平验证 + 收窄验证都要(排除倾斜盘整)。
- 各边至少 2 次触碰。

**两类共用**:结构成熟度 = 三角边线/箱体上下沿各至少触碰 2 次,结构才真实成型(宁少勿滥)。

## Requirements

- R1 改造现有「shrink」方法,升级为收敛结构检测(三角/低波动箱体),不新增 method。
- R2 全周期扫描(5m/15m/1H/4H/1D),每周期单独判定结构,一币一行。
- R3 每行输出:结构类型(三角/箱体/无)、结构内位置、收敛强度分。
- R4 结构检测用完整 swing 验证(自适应 N fractal),swing 定窗口。
- R5 方向双向(多头空头都选),不做方向过滤。
- R6 UI 参数面板极简化:扫描数量、最低成交额、扫描时间点、结构强度阈值。
- R7 修复当前机制缺陷:短周期瞬时噪声、相对非绝对、bw=3 塌陷、无结构验证。

## Acceptance Criteria

- [ ] AC1 实盘扫描:能选出处于收敛三角的币,且该币 K 线肉眼可见三角形态。
- [ ] AC2 实盘扫描:能选出处于低波动箱体的币(振幅相对自身收窄、水平无漂移)。
- [ ] AC3 短周期(5m/15m)不再因瞬时安静段误报(与旧方法对比抽样)。
- [ ] AC4 每周期独立出结构类型/位置/强度分,结果表正确展示。
- [ ] AC5 一币可跨周期显示(如 5m 三角 + 1H 箱体),覆盖盘整成长。
- [ ] AC6 结构强度阈值作为主旋钮,调高宁少勿滥。
- [ ] AC7 现有测试适配改造,`npm test` 全绿,`tsc` 干净。
