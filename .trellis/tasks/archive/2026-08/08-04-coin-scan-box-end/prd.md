# 选币模块-箱体末期检测

## Goal

给选币模块加"箱体末期"观察:找出当前处于**箱体**(水平震荡区间)、且接近**末期**(突破前兆)的币。让用户提前看到哪些币正在箱体末端蓄力,等待突破方向确认后介入。

## Background / Confirmed Facts

- 选币模块是插件式:`method` 参数可扩展,现有"缩量"方法(`src/domain/coin-scan.ts` 的 `computeQuietMetrics`、`src/server/coin-scan-service.ts`、`src/ui/CoinScanPanel.tsx`、`/api/scan`)。
- 现有缩量方法已产出:**量比、振幅比、连续平静根数、强度分**。这些是"量能平静"信号。
- 数据源:OKX SWAP K 线,服务层已能拉任意币、任意周期、任意根数。
- 扫盘周期:5m / 15m / 1H / 4H / 1D。
- 用户明确要求:**不参考** `bit-scan` skill 里的箱体定义(30 天高低振幅 <25%、箱体中轨=(最高+最低)/2)。箱体定义要重新设计。
- 浪浪体系里"箱体末期"对应:**阶段一**(突破大级别震荡箱体,放量长阳)与**阶段四**(大分歧结束再次突破)的**前兆**。
- 箱体与缩量的区别:缩量只看"量 + 波动"平静;箱体末期需要先**画箱**(定义水平边界),再看**位置**(价格贴近哪个边界)+ **结构**(反复触碰、收敛)。

**箱体定义(用户口述,浪浪体系,已定):**
1. 前置:**一段跌幅**(前期下跌段)。
2. 跌不动后反弹:跌幅**最低点 = 箱底**。
3. **反弹高点 = 箱顶**。
4. **二次探底**:价格从箱顶回落,再次测试箱底附近(确认箱底支撑有效)。
5. 二次探底后**收敛**(震荡收窄)→ **突破箱顶** → 开启**主升浪**。

**由此派生的设计约束(已定):**
- **方向锁定多头**:只找"准备向上突破"的箱体,不做空头箱。
- 需要**结构识别**:识别前期下跌段、箱底(跌幅最低)、箱顶(反弹最高)、二次探底低点 —— 需要 swing 点识别,非纯滚动窗口。
- **"末期" = 二次探底已完成、尚未突破、正在收敛蓄力**的状态。
- 突破确认(放量长阳破箱顶)属后续阶段,本次扫"突破前兆"。
