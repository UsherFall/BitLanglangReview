## 1. 度量定义

### 1.1 数据与窗口(必须先说明的硬约束)

- Bitget `1D` 硬上限 **90 根**;剔除未收盘 bar 后 **89 根**(2026-07-14 ~ 2026-10-10)。
- ⇒ 1D 上"前置大行情 + 盘整"最多只能装在 89 根里。**凡是大行情起点落在 index 0 的样本,其"大行情幅度"是被窗口截断的下界**(PROM 的 533% 就是这种情形;`barsBeforeImpulse = 0` 的样本全属此类)。见 §6 Caveat 1。
- 1D 一天一根,所以 `consolLen` 的最小可分辨单位是 1 天,`swingSpan` 同理 —— 结构量的**分辨率天然很粗**。

### 1.2 摆动点(取回 8/13 的 `detectSwings`)

```
swing high at i ⟺ high[i] > high[j] for all j ∈ [i-n, i+n], j≠i
swing low  at i ⟺ low[i]  < low[j]  for all j ∈ [i-n, i+n], j≠i
```
同向相邻摆动点合并到极值。`STRUCTURE_SWING_N = [2,3,4,5,6,8,10,12]`(与原实现一致)。

> **实测发现(重要)**:原 `probeStructure` 的择优规则是「touchCount 优先 / span 次之 / n 小者优先」。
> 在 17 个样本上**永远选中 n=2**(见 §7)—— 因为 n 越小摆动点越多。也就是说,当前的"摆动结构"
> 实质上是「**n=2 分形点计数**」,与"结构饱满"的相关性可疑(见 §6)。

### 1.3 三角/通道分类(取回 8/13 的 `classifyStructure`)

对盘整段内的摆动点,上边 = 高点价 OLS 回归、下边 = 低点价 OLS 回归:

| 量 | 公式 | 语义 |
|---|---|---|
| `highSlopePct` | `slope_high × span_high / meanHigh` | 上边总漂移(负 = 下压) |
| `lowSlopePct` | `slope_low × span_low / meanLow` | 下边总漂移(正 = 上抬) |
| `gapStart` | 首摆动点处 `(上边 − 下边) / 现价` | 起始通道宽 |
| `gapEnd` | 现价那根处 `(上边 − 下边) / 现价` | 末端通道宽 |
| `convergence` | `1 − gapEnd / gapStart` | >0 收敛,<0 张开,>1 表示两线已交叉 |
| `converging` | `0 < gapEnd < gapStart` | 「还在收敛、尚未交叉」 |
| `triQualified` | 原 `classifyStructure` **全部闸门**通过 | 严格三角(含 `minSpanTriangle=13`、`touchMin=2`、斜率破位、价格在通道内) |

原闸门:**通过严格几何 + 价格在通道内 + 跨度 ≥ 13**。本章额外把「末摆动点距今 ≤ 12 根」的
recency 闸**关掉**(1D 上末摆动点常在现价前 10~25 根,原闸会全数判死),改由 `consolStart` 隐含界定窗口。

### 1.4 「大行情 + 盘整」的拆分

给定 89 根已完成 bar,`L = 88`:

1. **`kind='extreme'`(主口径)**:在回看窗口 `[lo, L]`(`lo = L − impulseLookback + 1`)内取
   `hiIdx = argmax high`、`loIdx = argmin low`;两者各自作为"盘整段起点"候选。
2. 对候选 `consolStart`:
   - 上行候选(起点是高点):大行情起点 = 其之前的**最低点**,`impulseAmp = (high_c − low_s) / low_s`;
   - 下行候选(起点是低点):大行情起点 = 其之前的**最高点**,`impulseAmp = (high_s − low_c) / high_s`;
   - 需 `impulseAmp ≥ impulseMinAmp` 且 `L − consolStart + 1 ≥ minConsolLen`。
3. **取"更晚"的合格候选**(最贴近"大行情刚结束、现在在盘整")。
4. `kind='swing'` 变体:候选起点限定为 fractal 摆动点(其余同上);`maxImpulseBars` 可把大行情限制成一条有界单边腿。

**主口径参数**:`impulseLookback=89, impulseMinAmp=0.20, minConsolLen=8, kind='extreme', maxImpulseBars=0`。

### 1.5 盘整段上的度量

| 度量 | 公式 | 语义 |
|---|---|---|
| `impulseAmp` | 大行情幅度(高/低极值之间,相对起点价) | 「大行情有多大」 |
| `impulseBars` | 大行情耗时(根) | 大行情用了多久 |
| `impulseEfficiency` | 净位移 / 逐根 `|Δclose|` 之和 | 越接近 1 越单边 |
| `consolLen` | 盘整根数 | 「时间」 |
| `timeRatio` | `consolLen / impulseBars` | **时间比** |
| `consolRangePct` | `(maxHigh − minLow) / 现价`(盘整段) | 盘整区间 |
| `spaceRatio` | `consolRangePct / impulseAmp` | **空间比** |
| `consolAmpMedPct` | 盘整段单根振幅 `(h−l)/l` 的中位 | 绝对波动水平 |
| `ampRatio` | `consolAmpMedPct / impulseAmpMedPct` | 盘整比大行情安静多少(<1 = 变安静) |
| `consolLastRangePct` | 末 10 根(不足则全段)`(maxHigh−minLow)/现价` | 「末端是否收住」 |
| `swingCount` / `highCount` / `lowCount` | 盘整段内摆动点数 | 「结构走够没有」 |
| `swingSpan` | 末摆动点 idx − 首摆动点 idx | 结构跨度 |
| `legs` | `swingCount − 1` | 摆动腿数 |
| `structureScore` | `(clamp01(convergence) + clamp01(swingCount/8) + clamp01(swingSpan/40)) / 3` | 综合结构分(描述用) |

### 2.1 逐条读表得到的四个事实

1. **"空间比"方向是反的。** PROM 0.13 是全样本最小;负样本(0.14~0.50)整体比正样本还"空间小"。
   原因:空间比的分母是大行情幅度,而正样本的大行情(PROM 533%、ACE 516%)比负样本更极端,
   分母越大比值越小。**用户要的"盘整要有对应足够的空间"不能落成 `盘整区间 / 大行情幅度 ≤ b` 这个形式。**
2. **"时间比"方向对,但强度不够。** 正样本 0.45~3.79,负样本 0.16~1.43,重叠区在 0.45~1.43。
   单用 `timeRatio ≥ 0.45` → 7/7 正但放行 3 个负(ONE/UAI/AKE)。
3. **"收敛"只对 3 个正样本成立。** `converging` = PROM/RIVER/BLESS 三只;`triQualified` 同样是 3 只。
   负样本里 NIL 也通过严格三角(盘整 18 根、4 个摆动点、79% 区间 —— 一个高波动的楔形)。
4. **"摆动点数 / 结构跨度 / 综合结构分"看起来最干净**:`swingCount ≥ 7` 与 `structureScore ≥ 0.8`
   都做到 **6/7 正 + 0/10 负**,唯一例外都是 **CATI**。见 §3.

### 3.3 结论

- **在"收敛"这个维度上,新 5 正与旧 2 正明显不像**:旧 2 正 100% 收敛,新 5 正只有 20%(BLESS)。
  KAVA / CATI / ACE / SYN 的上下两条回归边**不收敛**(KAVA `conv` 1.10 = 已交叉;ACE 1.04 = 已交叉;
  SYN 1.08 = 已交叉;CATI −0.29 = 张开)。
- **7 只正样本真正的共同特征**(全部满足、而 10 个负样本里最多 6 只满足)是**四个"量"而不是"形"**:
  1. 前置大行情 **≥ 71%**(正样本最小 RIVER 71%;负样本里只有 BGB 39% 低于 70%);
  2. 盘整 **≥ 23 根**(负样本最多 30 根,只有 UAI 越线);
  3. `timeRatio` **≥ 0.45**;
  4. 盘整段摆动点 **≥ 7 个**(负样本最多 6 个)。
  ⇒ 一句话:**用户这次新增的 5 个"结构饱满"正样本,把评价标准从"收敛的形"推向了"盘整走得够久、摆动够多"。**
  这与用户原话"结构饱满然后收敛好的 / 三角是衡量走够的一种方法"一致 —— 但实测数据说明,
  起作用的是"**走够**",而不是"**收敛**"。
- **CATI 是例外中的例外**:7 个正样本里唯一 `conv < 0` 且 `structureScore` 只有 0.34 的;
  它的盘整是一段**微幅下飘的通道**(0.0585~0.0745),不收敛。它的入选更像是"大行情够大 + 盘整够久"
  而**不是**"结构饱满"。

## 6. 必须写明的四条 Caveat

1. **窗口只有 89 根,分辨率很粗。** 1D 上"大行情 30~60 根 + 盘整 20~60 根"就把窗口吃满;
   凡是 `impulseStart = 0` 的样本,其 `impulseAmp` 是**被窗口左端截断的下界**,
   不是真实的大行情幅度(PROM 533%、ACE 516% 都属此类)。这直接污染 `spaceRatio`(分母被放大)。
   **465 池里有 47 只(10.1%)的大行情起点落在窗口左端。**
2. **`swingCount` 与 `consolLen` 高度共线(465 池上相关 **0.911**)。** 按盘整长度分层看
   `swingCount ≥ 7` 的命中率:

   | consolLen | 池内数 | `swingCount≥7` 命中 | 命中率 |
   |---|---|---|---|
   | < 20 | 154 | 2 | 1.3% |
   | 20–29 | 84 | 24 | 28.6% |
   | 30–49 | 64 | 58 | 90.6% |
   | ≥ 50 | 123 | 123 | **100.0%** |

   ⇒ **"结构饱满"这个闸门在 1D 上几乎等价于"盘整 ≥ ~30 根"**。它不是一个独立的结构判断。
3. **当前择优规则永远选 n=2**(17/17),所以 `swingCount` = "n=2 分形点个数",
   对微小波动极敏感;它没有经过"哪个 n 才是合理的结构尺度"的检验。
4. **原实现在 1D 上不可直接复用**:(a) `recency` 闸(末摆动点距今 ≤ 12 根)在 1D 上会判死几乎所有
   盘整(实测末摆动点常在现价前 10~25 根);(b) `backscanWindow` 要求"末摆动点就是当前 bar",
   在 1D ~89 根上基本不成立。本报告把两者关掉,只保留几何判定 + 由 `consolStart` 限定窗口。
