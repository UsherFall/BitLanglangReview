## 1. 两种类型 + 共同前置的精确定义(本报告主推口径「族①」)

### 1.1 共同前置 —— 「原趋势已走出 / 停下」

**锚点定义(唯一、确定性、不需要搜索):**

```
t = argmax_{i∈[0..L]} close[i]  与  argmin_{i∈[0..L]} close[i]  中 「更晚」的那个
盘整段 C = [t .. L]              (窗长 len = L − t + 1)
原趋势 = 从反方向极值走到 t 的那一段(方向 dir = up / down)
```

**「已停下」判据:**

```
PRE:  |ln(close[L] / close[t])| ≤ D        (盘整段净漂移小)
```

**为什么这条就是"趋势走出":** 锚点已经钉在原趋势的终点上,若原趋势仍在延续,`[t..L]` 必然继续朝原方向走 → 漂移大。**漂移闸(D=0.2)直接收掉** MOVR(−40.1%)、NIL(−25.1%)、ONE(−52.7%)、AKE(−58.0%)、UAI(−57.1%);
**时间闸(len<TB=18)收掉** BTW(1 根)、WLD(9 根)、QNT(12 根)、MOVR(11 根)、NIL(17 根)。
两条闸**共同**对应用户原话"没走出下降趋势 / 还在跌 / 时间不够"。

**无趋势品种(BGB / TRX)怎么处理:** 天然通过。
它们的全窗口区间只有 **31% / 9.3%**、全窗口漂移只有 **+16.3% / +0.9%** —— 无论锚点落在哪,`[t..L]` 都满足"窄 + 无漂移"。定量:89 个候选起点里有 **70 / 72 个**同时满足箱体三条件 → **判定与锚点无关**。所以"用户认为它们合格"在口径上是自然的,不需要特例。

### 1.2 类型 A —— 三角收敛(复活 8/13 的 `classifyStructure`)

在窗口 `[t..L]` 上跑原机制(多档 `n ∈ [2,3,4,5,6,8,10,12]` 取最优),要求:

```
triQualified   = 原闸门全部通过(上下边 OLS + 斜率方向 + 斜率破位 + 价格在通道内 + 跨度 ≥ 13)
len ≥ TA       = 20        窗长够(时间)
span ≥ SA      = 20        结构跨度够(走够/饱满)
```

- `len` 与 `span` 是用户"**饱满**"的落点;**收敛本身**(`0 < gapEnd < gapStart`)由 `triQualified` 内含。
- 未采用原实现的 `recency` 闸(末摆动点距今 ≤ 12 根)—— 1D 上会把几乎所有盘整判死(见 `structure-measures.md` §6.4)。

### 1.3 类型 B —— 箱体震荡

```
len ≥ TB  = 18                   盘整时间够
range     = (maxHigh − minLow) / 现价 ≤ R = 45%    区间窄
|ln(close[L]/close[t])| ≤ D = 0.2                  箱体不是缓慢单边(前置 + 箱体性)
driftPerBar = |ln(...)| / len                      (诊断用)
```

**为什么区间窄之外还要"无净漂移":** 窗口区间 ≤ 45% 并不排斥"45% 的缓慢单边上涨"(WLD:窗长 24 根、区间 42%、净漂移 **+34.3%** —— 一路涨进去的)。漂移闸把"箱体"和"慢牛"分开。这是本轮新加的一条,也是它变得可用的关键。

## 3. 分离度 / 敏感性:哪个闸门在干活,哪里最脆

### 3.1 单闸门单动扫描(其余固定在主推点)

| 单动 | 正命中 | 负命中 | 池(464) |

| `D` = 0.10 / 0.15 / 0.20 / 0.25 / 0.40 / 0.60 | **7/9 全部不变** | **0/8 全部不变** | 9.1% / 11.9% / 14.7% / 15.3% / 17.0% / 17.2% |
| `D` = 0.05 | 4/9(掉 KAVA/CATI/BGB) | 0/8 | 4.5% |
| **`TB` = 16** | 7/9 | **0/8** | **31.7%** ← 从这掉下来一大块 |
| **`TB` = 17** | 7/9 | 0/8 | 15.1% |
| **`TB` = 18**(主推) | 7/9 | 0/8 | **14.7%** |
| **`TB` = 19** | 7/9 | 0/8 | 13.4% |

| **`TB` = 22** | **4/9**(掉 KAVA/BGB/TRX) | 0/8 | 9.3% |

**读法:**
- `R` 与 `D` 极宽(6 档、5 档都不变结论)→ 这两个参数**不是拟合出来的**。
- `TA` / `SA` 也几乎是平的 → 类型 A 极稳(**单用时池只 16/464 = 3.45%**)。
- **唯一锋利的参数是 `TB`。** 可行域 `{17,18,19,20}` 四个整数值。
  - 下界由负样本 **NIL(17 根)** 钉住 —— 与用户"**还差几天**"完全吻合,但也意味着**差 1 根就翻车**。
  - 上界由正样本 **KAVA / BGB / TRX(21 根)** 钉住 —— 余量 3~4 根。
- 次脆点:**RIVER 的区间 44% vs R=45%(1pp)**;但 RIVER 同时被类型 A 覆盖(`span 28` vs `SA=20`,余量 8),所以不致命。
- **负样本侧完全稳健:** MOVR / WLD / BTW / QNT / NIL / ONE / UAI 在 **任意起点 s ∈ [0..L]** 上都不满足类型 B 三条闸门(0/89),AKE 0/40。也就是说**负样本的拒绝与锚点取在哪无关**。

## 4. ACE / SYN 专项核查(必答项)

**问题原文:** 在"大行情锚定"下 ACE(盘整区间 132%)与 SYN(101%)既不收敛也不窄。换"走出趋势"的分段后能否覆盖?

### 4.1 答案:覆盖不了 —— 且不是阈值问题,是"锚点定义"在这两只上自相矛盾

**ACE —— 任何一致阈值都救不了(它在两种口径之间二选一):**

| 锚定口径 | 锚点 t | 窗长 | 区间% | 净% | 严格三角/跨度 | 能否过 B(len≥18 ∧ 区间≤45% ∧ 净≤20%) |
|---|---|---|---|---|---|---|
| 收盘极值 | 30 | 59 | **142** | −32.2 | . /54 | ✗ 区间太宽 |
| 高低极值 | 31 | 58 | **132** | +5.2 | . /54 | ✗ 区间太宽 |
| ZigZag θ=0.15/0.20/0.25 | 73 | **16** | 40 | −18.3 | . /11 | ✗ **窗长 16 < 18** |
| ZigZag θ=0.30/0.35 | 63 | **26** | 48.9 | +26.9 | **Y** /21 | ✗ 区间 49% > 45%、净 27% > 20%(但此时**类型 A 会命中**) |
| ZigZag θ=0.40 | 0 | 89 | 169 | +161.8 | . /81 | ✗ |

**关键矛盾:** ACE 要合格,锚点必须落在 **idx 63 附近的"下跌结束处"**,而这要求 ZigZag θ ≥ 0.30(否则枢轴停在 73,窗长只有 16)。但 **θ ≥ 0.30 会同时把 RIVER 的锚点推到 idx 0**(窗长 89、区间 216%、三角不成立)→ **RIVER 直接掉出**。
⇒ 这是**同一参数下两只正样本互相排斥**,不是调参能解决的。

**SYN —— 更彻底:任何 ZigZag θ 都没有合格窗口:**

| θ | 锚点 t | 窗长 | 区间% | 净% |
|---|---|---|---|---|
| 0.15 | 77 | **12** | 26 | +17.3 |
| 0.20 / 0.25 / 0.30 / 0.35 / 0.40 / 0.50 | 0 或 61 | 89 或 28 | **104 / 101** | −24.1 / **+150.7** |

SYN 的形状是:收盘最低 0.0788(idx 61)→ **一根 +131% 跳空**(idx 63)→ 之后 25 根在 0.168~0.24 震荡。
- 锚在"最低收盘"(61)→ 窗口把跳空和 +150.7% 全包进去 → 区间 101%、漂移 +151%。
- 锚在跳空之后(69/77)→ 窗长只有 12~19 根。
- **在 θ∈[0.10,0.50] 全区间内,不存在"窗长 ≥ 18 ∧ 区间 ≤ 45%"的窗口。** SYN 只在"允许起点搜索"的读法下才能凑出 2 个合格起点(s=70/71,窗长 19/18)。

### 4.2 那"存在窗口"读法能不能救?

能凑到 9/9,但代价明确:

| B 规则读法(TB=18, R=0.45, D=0.20) | 正命中 | 负命中 | 池通过 |
|---|---|---|---|
| **单锚定(一致、可复现)** | **5/9** | 0/8 | **59/464 = 12.7%** |
| 存在窗口(∃s) | **9/9** | 0/8 | **368/464 = 79.3%** |

- 「存在窗口」族在整个参数网格上有 **465 组 9/0 解**,但**最紧的一组池通过率仍是 307/464 = 66.2%**。
- 换成 `max(收盘极值, ZigZag-0.15 末枢轴)` 这类混合锚定:只有 **10 组 9/0 解,全部要 TB=10**(即"箱体只要 10 天" —— 直接违反"时间足够",也放 WLD 的近邻进来),池通过率仍 46%~50%。
- **另有一条硬约束:** 若只靠类型 B 收 SYN,必须 `TB ≤ 19`(SYN 只有 19 根);而 `TB ≤ 16` 会把 NIL(17 根)放进来 —— 也就是说 **NIL 与 SYN 在时间轴上只差 2 根**,参数必须钉死在 `TB ∈ {17,18,19}`。

**⇒ 一句话:ACE 与 SYN 是这 17 点上真正"分不开"的两只。**
用一致口径:漏这 2 只(7/9),但池只要 14.7%。
要全收:必须放弃"锚点一致",池通过率升到 **2/3 以上** —— 那就不是一个筛选器了。

## 6. 89 根窗口限制的影响

| 事实 | 数字 | 影响 |
|---|---|---|
| 1D 硬上限 | Bitget 最多返回 **90 根**,剔未收盘后 **89 根** | 一天一根 ⇒ 所有"时间/跨度"的量最小分辨单位 = 1 天;盘整 20 根 ≈ 3 周 |
| 全池 K 线根数 | 80~89 根:**453** 只;60~79:3;40~59:5;<40:**3** | 几乎所有标的都卡在 89 根上限 |
| 锚点位置分布 | `t=60..88`:**376 只(81.0%)**;`t=30..59`:63(13.6%);`t=15..29`:17;`t=5..14`:6;`t=0..4`:**2(0.4%)** | 锚点普遍很靠近现价 ⇒ 我们实际只在"最近 3 周~3 个月"里做判断 |
| **截断风险** | 锚点落在 `t ≤ 14` 的 8 只(1.7%) | 说明"盘整已经长于 89 根"→ 锚点被推到窗口左端,盘整区间被前面的行情撑大 → 会被区间闸误拒 |
| AKE | 只有 **40 根** | 任何"盘整 ≥ 18 天"的判据对它都是**数据不足**,而不是"结构不对"。它是负样本(结论正确),但这个拒绝理由应单独标注 |
| 类型 A 的窗口占用 | PROM `t=46`(43 根)、BLESS `t=36`(53 根) | 结构窗口只占窗口一半;若历史更长(如 300 根),PROM/BLESS 的"原趋势"标定可能变化 —— 上一轮已证"锚定方式决定结论" |

**额外一条(取回实现时必踩的坑):** 8/13 的原实现有两个闸在 1D 上不可直接用 ——
(a) `recency`(末摆动点距今 ≤ 12 根):1D 上末摆动点常在现价前 10~25 根,会判死几乎所有盘整;
(b) `backscanWindow`(要求末摆动点就是当前 bar):在 ~89 根上基本不成立。
本报告把两者都关掉,只保留几何判定 + 由锚点 `t` 限定窗口。

## 8. Caveat 与未决

1. **7/9 不是"已验证",是"一致口径下的上界"。** 与上一轮 `decline` 口径的失败模式一样:17 个点上"能分开"本身不是证据。本轮至少做到了两件上一轮没做到的事:(a) 结论对 `R`/`D`/`TA`/`SA` 完全不敏感;(b) 负样本的拒绝是"锚点无关"的(0/89)。但 **`TB` 仍由 NIL 的 17 根钉死,余量 1 根**。
2. **ACE / SYN 的结论是"分不开",不是"阈值没调好"。** 详见 §4:三个独立口径(收盘极值 / ZigZag θ 全区间 / 混合锚定)都无法同时覆盖它们与其邻居,且 ZigZag 上两只的要求**方向相反**。
3. **`t` 取"更晚的收盘极值"是一个选择,不是唯一解。** 换成高低极值后同样 7/9 但正样本集合不同(TRX 会通过类型 A、CATI 区间变 25%),说明"锚点怎么定"仍是最大的不确定源。建议把它当成**待与用户确认的口径**,而不是定论。
4. **类型 A 的 `triQualified` 在 1D 上偏严:** 7 个正样本里只有 3 只(PROM/RIVER/BLESS)通过;KAVA/CATI/BGB/TRX 的上下边**已经交叉**(`convergence > 1`,`gapEnd ≤ 0`),`classifyStructure` 直接判 `noConverge`。也就是说"收敛"这一维在 1D 上只能认出**尚未交叉的三角**。这与用户"收敛不一定是三角"的说法一致,但会让用户以为"KAVA 是三角"的期待落空。
5. **未做的事:** ① 未在更大样本(465 池)上人工抽检命中名单,无法判断 14.7% 的池通过里有多少真阳性;② 未验证 4H / 1H(TIA/DOT 的"趋势线走完"法,PRD R3)在本口径下的表现;③ 未把本口径与旧 `detectConvergence` 的输出集做交集/差集对比。
6. **AKE 的拒绝理由需单独标注**(仅 40 根数据,不是"结构不对")。
