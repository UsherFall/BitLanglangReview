## 1. 口径 v3 的精确定义 + 本轮的两处升级

### 1.1 v3(用户第六轮)

对每只的 89 根已完成 1D:

```
止跌:   最低点出现在 ≥ k 根前(此后不再创新低)
像样反弹: 自该低点的反弹幅度 ≥ R
盘整:   之后形成 (三角收敛: 上边下压 + 下边上抬) 或 (箱体: 区间窄 + 时间够)
例外:   无趋势品种(BGB/TRX)免"反弹"要求
```

### 1.2 升级①:摆动点去重

摆动点 = 分形极值 `high[i] > high[j] ∀j∈[i−n,i+n]`,`n ∈ {2,3,4,5}`;再做**同向相邻合并到极值**(同一段里连续的 high 只保留最高的那个)。本轮实测:去重对 ACE 只改变 conv 0.83→0.85(§2),但它是窗口搜索不退化出重复点的前提。

### 1.3 升级②:窗口搜索(本报告的核心新增)

不再只用一个锚点,而是:

```
for W in [Wmin..Wmax]:              # 默认 [14, 89]
    start = len-1 - W + 1
    for n in [2,3,4,5]:
        在 [start..L] 内检测摆动点(去重)
        上边 = 摆动高点 OLS,下边 = 摆动低点 OLS
        gapStart = 首摆动点处通道宽 / 现价
        gapEnd   = 现价那根通道宽 / 现价
        conv     = 1 − gapEnd/gapStart
        合格 ⟺ span ≥ minSpan ∧ 上边下压 ∧ 下边上抬 ∧ conv ≥ θ (∧ 未交叉: gapEnd > 0)
记录: nPass(合格窗口数)、bestPass(最收敛的合格窗口)
```

**"止跌"的诚实说明:** 只要把"最低点"定义为全窗口最低 low,则"此后不再创新低"**恒为真**(同义反复)。本报告因此改用两个可证伪的量:`lowAge`(全窗口/近 60 根最低点的年龄)与 `lastNewLowAge`(最近一次创 20 根新低距今多少根)。**这两个量都分不开正负**(§4.2)。

## 5. 稳健性 / 泛化:三角窗口搜索的失效模式(最重要)

### 5.1 "人人都能找到收敛窗口" —— **是真的**

在**全 465 加密池**上,统计每只"合格窗口数" `nPass`:

| 门槛 | 池通过 | 占比 |
|---|---|---|
| `nPass ≥ 1` | **313** | **67.3%** |
| `nPass ≥ 3` | 298 | 64.1% |
| `nPass ≥ 5` | 259 | 55.7% |
| `nPass ≥ 10` | 214 | 46.0% |
| `nPass ≥ 20` | 108 | 23.2% |
| `nPass ≥ 30` | 56 | 12.0% |
| `nPass ≥ 40` | 28 | 6.0% |
| `nPass ≥ 50` | 13 | 2.8% |

- 松口径(上边下压 + 下边上抬 + conv≥0.3、W∈[14,89]、n∈{2,3,4,5}):**2/3 的池子都存在至少一个"收敛三角窗口"**。
- 加"两线未交叉"约束后仍 **241/465 = 51.8%**。
- 只有把门槛推到 `nPass ≥ 30` 才降到 12%,但那时正样本只剩 3/8。
- ⇒ **窗口搜索本身是一个"普适性质发生器":给定足够多的窗口起点,绝大多数币都能被凑出一个收敛窗口。它不能单独作为判据。** 上一轮"存在窗口"读法把类型 B 从 12.7% 吹到 79.3%,本轮在三角支上复现了同一现象(67.3%)。

### 5.2 窗口起点的敏感性(ACE 的正反面)

- **反面(敏感):** ACE 从 W=59(conv 0.85,未交叉)到 W=60(conv 1.04,交叉)**只差一根 bar**,结论从"标准三角"翻成"已交叉"。**窗口锚定差一根就翻天** —— 这正是上一轮在固定锚点下把 ACE 误判为"不收敛"的原因。
- **正面(平台):** ACE 在 W=55–59 是**平台**(五根窗口同值);合格窗口 21~50 个。
- ⇒ 窗口搜索**修好了"锚点选错"的敏感性**,但代价是**丧失了选择性**(5.1)。两者是同一个机制的两面。

### 5.3 与上一轮口径的对比

| 口径 | 正 | 负 | 池 |
|---|---|---|---|
| 上一轮 `类型A ∨ 类型B`(一致锚点) | 7/9(老口径) | 0/8 | 68/464 = 14.7% |
| 上一轮 `存在窗口` 读法 | 9/9 | 0/8 | 368/464 = 79.3% |
| **本轮 v3(8/9)** | **6/8**(0 负的最好情形) | 0/9 | 208/465 = 44.7% |
| **本轮 v3(8/8 并集)** | **8/8** | **2/9** | **310/465 = 66.7%** |

**结论:** 换成 8 正/9 负后,上一轮"14.7% 的紧口径"**再也达不到**(它靠的是 SIN 不算负 + 一致锚点);一旦为了 PROM/CATI/ACE 打开三角搜索这条门,**池通过率就回到 2/3**。**这与上一轮是同一种失败:正样本的覆盖需求与负样本的排除需求在"三角"这条轴上直接冲突。**

## 6. Caveat 与未决

1. **v3 未通过验证。** 与上一轮一样,**17 个点上"能凑出 6/8 或 8/8"本身不是证据**;本轮至少做到了:结论对"反弹""止跌"两个维度是**否定的**(0/8、完全重叠),且"池爆到 67%"在更大样本上被证实。
2. **"像样反弹"的结论限定在 1D 全窗口 + 幅度口径。** 已试 6 种派生量(峰值/收盘/现价/回吐/新低龄/中位),全部重叠。**若用户的本意是"小级别里那一段拉起"**(第六轮原话:"小级别拉起来收敛"),那这条维度应当放到**第 2 段(小级别)** 去验,而不是 1D。本报告只能证明:**在 1D 上没有区分力,且方向相反。**
3. **"止跌"在 1D 全窗口上近乎同义反复。** 若改用"分段低点"(如 ZigZag 枢轴)会重新引入锚定敏感性问题(上一轮已证 ZigZag 对 ACE/SYN 要求互相矛盾)。
4. **AKE 只有 40 根**(2026-09-01 起)。它被拒是"数据不足",不是"结构不对",应单独标注。
5. **1D 硬上限 90 根**(剔未收盘 89 根)⇒ 任何"盘整 ≥ 20 天"的判据分辨率只有 1 天;盘整长于 89 根的样本无法表达。
6. **未做:** ① 4H / 1H(TIA/DOT 的"趋势线走完"法,R3);② 命中名单的人工抽检(无法判断 44.7% 里有多少真阳性);③ 与旧 `detectConvergence` 输出集做差集对比。
