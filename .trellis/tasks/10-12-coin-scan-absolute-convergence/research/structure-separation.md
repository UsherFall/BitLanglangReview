# Research: 结构口径能否分开 7 正 / 10 负 —— 分离度评估与结论

- **Query**: 在 7 正 vs 10 负 上找"能分开"的参数区域;如实报告能/不能、哪几只顽固分不开;并做参数敏感性
- **Scope**: mixed(内部口径 + Bitget 1D 实盘)
- **Date**: 2026-10-12
- **数据快照**: `.scratch/conv-cache/*-1D.json`(anchor `2026-10-12T12:34Z ~ 13:03Z`,89 根已完成 bar)
- 度量定义见 `structure-measures.md`;原始数据见 `data/structure-*.csv`
- 复现:`node .scratch/struct-separate.ts` / `struct-anchor.ts` / `struct-rules.ts`

## 0. 结论(先说答案)

1. **能分开,但是"连乘"而不是"结构"。**
   任意**单条**闸门都无法做到 7 正 0 负(候选 **118** 条单闸门全扫,**0 条**);
   但 **2 闸门组合有 3 个、3 闸门组合有 147 个**能做到 7/0。
   而所有 7/0 的组合**清一色是"长度 / 数量"类闸门**(`consolLen`、`timeRatio`、`impulseAmp`、
   `consolRangePct`、`swingCount`、`consolLastRangePct`),**没有一个是"收敛性"闸门**。
2. **"收敛性"这一维度在标注集上没有区分力,而且方向常常是反的。**
   - `converging`(0 < gapEnd < gapStart):**3/7 正 + 2/10 负**;
   - `triQualified`(严格三角):**3/7 正 + 1/10 负**(漏 NILUSDT);
   - `convergence ≥ 0.5`:**6/7 正 + 6/10 负**(6 个负样本的"收敛度"比正样本还高,因为它们的
     两条回归边已经**交叉**了,gapEnd ≤ 0 使 `1 − gapEnd/gapStart > 1`);
   - `triScore`(原三角得分 ≥ 0.5):**3/7 正 + 2/10 负**(PROM/RIVER/BLESS vs UAI/NIL);
     其余 11 个样本因两条边已交叉、`gapEnd ≤ 0`,`classifyStructure` 直接返回 NaN 得分 ——
     **正负样本被同一个"已交叉"的坑吃掉**,这一维度等于没测。
   ⇒ **用几何收敛(三角)做闸门,既丢正样本,又挡不住负样本。**
3. **唯一接近"单闸门干净分离"的是结构量的连乘体 `structureScore`**:
   `structureScore ≥ 0.8` → **6/7 正 + 0/10 负**(唯一丢 CATI);`swingCount ≥ 7` 同样 6/7 + 0/10。
   但它与盘整根数相关 **0.911**,实质上是"**盘整 ≥ ~30 根**"的代理(见 `structure-measures.md` §6.2)。
4. **最关键的负面结论:这套口径在 465 池上非常宽 —— R-A 通过 129/465 = 27.7%,
   而旧检测器 1D 只通过 45/465 = 9.7%。** 「17 点上 7/0」不等于「有区分力」。
   它的定位只能是「旧检测器输出集的二次粗筛」:在 45 只里把 10/10 已知负样本剔除、7/7 已知正样本留下,
   得到 20 只(含 13 只待确认)。
5. **结论对「大行情在哪结束」的定义高度敏感**(这是本轮最大的脆弱点):
   把锚定从"窗口极值"换成"最近摆动极值",7 个正样本的盘整段全部缩到 11~16 根,
   `consolLen ≥ 20` 一条闸门就能把 **7/7 打成 0/7**。

实测 7 个正样本在该定义下的盘整长度全部只有 **11~16 根**:

| CATIUSDT | 23 | **12** |
| BLESSUSDT | 53 | **14** |
| ACEUSDT | 58 | **15** |

⇒ `consolLen ≥ 20` 一条闸门就把 7/7 打成 **0/7**。
**「大行情在哪结束」不是细节,它决定了整条结论。** 这与上一轮 `decline` 口径
"脉冲选点一挪就散"是同一类脆弱性。

### 5.3 `swingCount` 的共线性(为什么"结构饱满"这个说法要打折扣)

465 池上 `swingCount` 与 `consolLen` 的相关 = **0.911**;按盘整长度分层看 `swingCount ≥ 7` 命中率:
`<20 根 → 1.3%`、`20–29 → 28.6%`、`30–49 → 90.6%`、`≥50 → 100.0%`。
⇒ 这条"结构饱满"闸门在 1D 上**几乎就是"盘整 ≥ 30 根"**。它不是独立的结构判断,
所以 R-A 里"结构饱满"这一环的**证据强度远低于它的字面含义**。

## 6. 分不开 / 顽固的样本

### 6.1 严格意义上"无论怎么调都分不开"的样本:**没有**

单闸门做不到,但 2~5 闸门组合可以做到 7/0。所以不存在"数学上不可分"的样本。
真正的问题是:**分离所依赖的支点极窄,且每只顽固样本都把某个阈值钉在边界上。**

### 6.2 三只一挪就破的"支点样本"

| 样本 | 角色 | 为什么顽固 |
|---|---|---|
| **CATIUSDT**(正) | 唯一的"结构弱正样本" | `conv = −0.29`(两条回归边**张开**,7 个正里唯一)、`structureScore = 0.34`(次低 0.83)、摆动点只有 **5** 个(正样本里最少)、`swingSpan = 16`。它把 `swingCount ≥ 5` 钉死在**唯一可行值**上(余量 0),把 `timeRatio ≥ 0.4` 钉到 0.451(余量 0.051)。**它是整条规则里最先被杀掉的样本。** |

| BTWUSDT | **拆分失败**:窗口极值就在现价附近 ⇒ 盘整 < 8 根(仍在趋势中) |
| TRXUSDT | **拆分失败**:89 根内最大振幅 < 20%,压根没有"大行情"(一直很平) |

### 6.4 正向困难:丢掉的 4 个新正样本

如果为了选择性收紧到 `structureScore ≥ 0.8` / `swingCount ≥ 7`,丢掉的永远是 **CATI**;
再收紧到"必须收敛"(`triQualified`),丢掉的变成 **KAVA / CATI / ACE / SYN**(4/5 个新正样本)。
⇒ **`CATI / KAVA / ACE / SYN` 与"收敛的三角"这个描述并不相符** ——
这不是阈值的毛病,是"收敛性"这个维度本身与用户的这 4 个标注不一致。

## 7. 一句话总结

> 结构量能在 17 个标注上做到 **7 正 0 负**,但**不是靠"收敛"**:
> 所有的"收敛性"度量(严格三角 / 收敛度 / 已交叉判定)在这批标注上**既丢正样本又挡不住负样本**;
> 真正起作用的是"**大行情 ≥ 50% + 盘整 ≥ 20 根 + 时间比 ≥ 0.4 + 摆动点 ≥ 5 + 末端 10 根 ≤ 40%**"
> 这五条"长度/数量"闸门的连乘,而其中"摆动点"与"盘整根数"相关 0.911,基本是同一件事。
> 更关键的是:**这套口径在 465 池上通过 129 只(27.7%),比旧检测器的 45 只(9.7%)宽 3 倍**,
> 且结论完全依赖"大行情在哪结束"的锚定方式(换成摆动点锚定即 0/7)。
> ⇒ **可以把它当作"旧检测器输出集的二次粗筛"(45 → 20,10/10 负样本剔除、7/7 正样本保留),
> 但不宜把它当成有区分力的 1D 结构筛选器,也不能宣称"结构饱满 + 收敛"这个口径已被验证。**
> 与上一轮 `decline` 口径的失败模式一样:**在 17 个点上"能分开"是拟合,不是证据。**
