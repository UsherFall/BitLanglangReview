# 设计：三步产线（粗筛 → 标线 → 报距离）

## 1. 边界

```
┌──────────────────────────────────────────────────────┐
│ 第 1 步  粗筛（算法，可很粗）                          │
│  输入：全池 1D 日线                                   │
│  输出：候选币 + 拉升区间 [起始日, 顶日] + 涨幅         │
├──────────────────────────────────────────────────────┤
│ 第 2 步  标压力位（人工，唯一信源）                     │
│  输入：第 1 步的区间图                                │
│  输出：该币的水平线（可多条）                          │
├──────────────────────────────────────────────────────┤
│ 第 3 步  每日播报（纯算术）                            │
│  输入：今日收盘、昨收、用户线                          │
│  输出：当天涨跌幅 %、距上方最近一条线 %（或"已破线"）   │
└──────────────────────────────────────────────────────┘
```

三条边界铁律：

1. **第 1 步不产出任何“结论”**——只有区间与涨幅。没有顶、没有收敛、没有分数。
2. **第 3 步不读取任何判据**——它只做减法和除法。任何“阈值判断”都不属于这里。
3. **两段之间唯一的耦合是“用户在哪段时间里画了线”**。

## 2. 粗筛定义（v3）

全部相对该币自身，无绝对百分比阈值：

```
from = E - 90                         // 回看窗口（唯一的时间窗口，且只用于"找拉升"）
lo   = [from, E] 内最低收盘 → loAt
P    = [loAt, E] 内最高价 → pAt
gain = (P - loC) / loC                // 这波涨幅
保留条件：
  gain ≥ 0.30                         // 相对量：涨了三成
  pAt - loAt + 1 ≥ 4                  // 至少 4 天（过滤单根插针）
  giveback = (P - Lmin_after_pAt) / (P - base) ≤ 0.60
                                      // 拉起来又跌回去一半以上 → 这波已废
输出：{ inst, s0: 起始日, p: 顶日, gain, fromPeak, holdDays, todayPct }
```

- `0.30` / `0.60` / `4` 都是**形状参数**，不是“这币好不好的阈值”。它们只决定“多大一段算一段拉升”。
- 实测规模：443 个池 → 85 个候选（约 19%）。

## 3. 距离定义（第 3 步）

```
price  = 今日收盘
above  = 用户线里 > price 的那些，升序
nearest = above[0] ?? null
toLevel = nearest == null ? "已破线" : (nearest - price) / price * 100
pct     = (price / prevClose - 1) * 100
```

- **取上方最近**而不是“全部列出”：用户 10/20 选定。
- 实测：与“距用户自己那条线”中位完全一致（8.11% vs 8.11%），因此不会因为多线而失真。
- `已破线` 而不是负距离：负的“还差 -3%”读起来是“已经过了 3%”，容易被当成“离压力位 3%”，必须显式区分。

## 5. 取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| 粗筛要不要认横盘 | **不认** | 实测与随机不可分（1.0×），继续加判据 = 重走 16 条失败路 |
| 回看窗口 90 天算不算“固定窗口” | **算，但只用于找拉升** | 失败清单禁的是“用固定窗口切出要判断的那一段”；这里窗口只界定“多长算一次异动”，横盘段由用户画 |
| 线的来源 | **只有用户** | HANDOFF §4：压力位永远用户标 |
| 是否保留“离顶多少” | 保留，**只作为粗筛的排序依据** | 让用户先从最接近顶的看起，但它不进入第 3 步 |

## 6. 风险

| 风险 | 应对 |
|---|---|
| 粗筛漏掉用户关心的币 | 用户可在第 2 步手动加币（第 3 步对任何有线的币都能播报，不依赖粗筛） |
| 用户线的“位置”与画线时的区间绑定 | 第 3 步只认 `price` 与线，不认区间；区间只用于画图 |
| RWA/股票混入 | `isRwa` 剔除，与项目同源 |
| 日期错位一天 | 全部走 `dayOf = toISOString().slice(0,10)`，不加减 8 小时 |
