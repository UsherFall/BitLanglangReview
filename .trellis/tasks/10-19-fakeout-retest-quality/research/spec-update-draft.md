# 收敛扫描判据换血：位置（retention）取代「后面比前面安静」（2026-10-19，研究结论）

> 这节是**研究结论与后续方向**，不是已上线行为；上线前不得据此修改 `detectConvergence` / `detectBoxBrace` / 行排序。
> 完整证据：`.trellis/tasks/10-19-fakeout-retest-quality/research/findings.md`。

## 触发

线上扫描把 CFX 排在第一位，用户判读为“假突破回来但没踩住”。复算确认：CFX 在 10-09/10-10 冲高 55% 后阴跌回吐，`detectConvergence` 仍判合格（`score = 0.716`）、`detectBoxBrace` 也判合格（箱高仅为“前段行程”的 0.36，而那段“行程”正是两根插针）。

## 根因

两者测量的都是“**最近比之前安静**”：

- `detectConvergence`：band 的中位振幅 vs **等长前一段**；
- `detectBoxBrace`：窗口箱高 vs **前 10/20/40 根里最宽**的行程。

它们都不知道“前面那段是什么形态”，也从不看“价格停在哪儿”。因此“冲高后阴跌横盘”和“主升浪走完后的高位横盘”在两者眼里是同构的。

## 实测：现有 score 是反向的

282 条可用人工标签（Y 36，随机基线 12.8%）：按 `score` 排序，前 10% 的 Y 占比 **7.1%**，低于基线；提高门槛 Y 占比继续下降（10-18 的 285 条分析已记录同一结论）。

## 已证伪的替代路线（不要再试）

| 路线 | 结果 |
| --- | --- |
| 回踩质量（回踩位置 + 阴跌动量） | 用户否决（过复杂）；前提也错——WAL 是真突破 |
| 按「最近一段行情」分段（z-score / 效率比 / 最小幅度） | CFX 在任何一种认法下都能混过去；12 张回放卡片本就是现行检测器输出，不能当基线 |
| 绝对收敛（最近 N 天区间 ≤ x%） | 33 段用户标注好区间只覆盖 8/33（20 天 ≤25%）；用户认可段里有 26%~60% 宽的 |
| 收缩度量（20 天高度/90 天高度、逐级收窄） | 前 10% 精准率 7.1%~10.7%，与基线无异；与位置相乘后反而变差 |
| 「第一次回到顶部」事件化 | 误杀 WAL/BEAM/AXL/TIA/OPG/STRK（好结构常在高位连续待一两周） |

## 推荐判据：`retention`

```
窗口 = 最近 60 根日线（初始标定值，可调）
lo   = 窗口内最低价
hi   = lo 之后窗口内最高价
retention = (lastClose - lo) / (hi - lo)        // 1 = 仍贴顶，0 = 跌回起点
offHigh%  = (1 - lastClose / hi) * 100
```

- 不需要写死 90 天：区间**起点由数据给出**（窗口内最低点）；
- 单币对照：WAL 0.87 / CFX **0.07**；
- 285 条：前 10% 精准率 **35.7%**、最差 1/4 只有 4.2%；
- 全池排名版（679 币 × 410 天，锚点日）：按当天全市场排名取**前 10%（约 64 个/天）→ 精准率 40%**；前 5%（34 个/天）25%；
- 33 段备注好区间逐日回放：前 10% 覆盖 **12/18**，前 20% 15/18。

**用法必须是「当天全市场排名前 X%」而不是绝对阈值**：样本里位置 ≥0.6 的只有 4% 的币，任何绝对门槛都会随行情与币种漂移。

## 已知性质（必须一起记）

1. 它是**强势币筛选器**：36 个 Y 里 30 个最近 60 天涨幅 > 60%（涨幅 ≤40% 的只有 GWEI 28%、TRX 9%）。这是用户的实际偏好，不是缺陷；反过来筛“刚从小底拉起来”的币会干掉 34/36 个 Y。
2. 相对排名在熊市仍会选出“相对最高”的 64 个，不保证绝对好看。
3. 它无法区分“高位横着等突破”和“高位做头”——留给人工判读。
4. 人工画线对提升选品精度**尚无证据**（用户想要的“底部拉起→箱体上沿→收敛”在 36 个 Y 里只有 GWEI 接近），定位为标注/交易计划工具。

## 落地约束（若采纳）

- 新增一层筛选/排序，**不改** `score` 语义与 `StructureResult` 行契约（10/12 决策）；
- 粗筛（池内分位 + `posRange ≥ 0.03`）与扫描池不动；
- 数据获取：全池一年日线必须用 `/candles` + `/history-candles` 正确翻页（`endTime = oldest`，见 market-data.md 的 TRAP 条目），单次 `1D` 仍受 90 根上限限制。
