# 收敛结构-回溯窗口检测(破斜率终止+容忍度)

## Goal

重构收敛结构检测的窗口确定机制:从固定"最近 8 个 swing"改为**回溯扫描** —— 从最新 K 往回扫,逐步确定形态边界,破斜率即终止。三角/箱体的结构识别更符合人眼分段直觉,减少 INTC 式(把 103 尖峰框进箱体)和 HEI 式(深跌腿误判)误判。

## Background / Confirmed Facts

- 当前机制:`probeStructure` 在固定窗口(最近 `DEFAULT_MAX_STRUCTURE_SWINGS=8` 个 swing)上跑候选 N=[2,3,4,5,6,8,10,12],选最规整结构。
- 缺陷:
  1. **固定 8-swing 窗口**:没有结构起点检测。INTC 15m 把更早的 103 尖峰框进当前箱体,用户肉眼从 00:45 开始看是箱体。
  2. **单调性用百分比容差**:HEI 0.1816 深跌腿(7.8%)被判"破单调"或"离群"不自然。
  3. **三角最少触碰太松**:touchMin=2,3+3 swing 就判三角。
- 用户确认的修复方向(本次讨论结论):
  1. **回溯扫描**:从最新 K 往回扫,破斜率终止,确定形态起点。
  2. **swing 检测 = 方案 B**:大窗口(100 根)一次性 detectSwings(候选 N),往回扫扫的是 **swing 序列**,找最后一段满足形态条件的连续子序列。swing 检测与形态边界扫描分离,只检测一次。
  3. **破斜率判定 = 单根插针即破,但区分毛刺**:影线穿透不算,收盘穿透趋势线超容忍度才算真破。
  4. **容忍度 = 收盘穿透 ≤ X% × 当前结构宽度**(建议 20% 起试)。
  5. **B(最小成形跨度)**:三角 12-13 根起试,箱体 5 根。B 每周期一致(形态以根计,不看真实时间)。
  6. 单调性判定待重新设计(用户质疑百分比容差,倾向"相对结构自身")。
- 前身任务:`08-07-coin-scan-convergence-structure`(swing 结构检测 v1)、`08-07-coin-scan-flat-relative-amplitude`(XRP 平边门)已归档。

## Requirements

- R1 窗口确定改为回溯扫描:从最新 K 往回,逐步确定形态边界,破斜率终止。
- R2 swing 检测用方案 B:大窗口一次性 detectSwings(候选 N),往回扫扫 swing 序列找连续形态段。
- R3 破斜率判定:单根插针即破;影线穿透不算,收盘穿透趋势线超容忍度才算真破。
- R4 容忍度 = 收盘穿透 ≤ X% × 当前结构宽度,初始 20%。
- R5 B(最小成形跨度):三角 12-13 起,箱体 5。每周期一致。
- R6 单调性判定重新设计(相对结构自身,非固定百分比)。
- R7 三角每边最少触碰维持 touchMin=2(用户确认)。
